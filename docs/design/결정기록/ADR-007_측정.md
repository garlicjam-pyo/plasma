# ADR-007 · 측정 계획 — 웨이퍼형 FHP 배열이 주 센서, 랭뮤어·컷오프·B-dot은 보조

- **상태**: 채택
- **날짜**: 2026-11-05 (1차 발표)
- **확신도**: 중간
- **관련**: 상세설계보고서 결정 7, `docs/측정계획.md`, `sim/jacobian_fit.py`, 백로그 B16

## 맥락
랭뮤어 탐침은 EEPF를 주는 유일한 수단이지만 한 점씩 재고 RF 보상이 까다로워 제어용 센서로는 맞지 않는다. KC20의 웨이퍼형 FHP 배열(29점)과 교재 5장의 2차원 배열(약 1 s에 전 점 측정)이 선례다.

## 결정
- 주 센서: 웨이퍼형 FHP 배열 13–17점 (0 mm 1, 25 mm 4, 75 mm 4, 140 mm 4–8).
- 보조: 랭뮤어 탐침 1–2개(이동 스캔, EEPF로 국소/비국소 판정), 컷오프 탐침 1개(중앙, 절대 밀도 교정), B-dot(표피 깊이, 장 모델 검증), 코일 전류·위상 센서(안쪽 루프).
- 전체/분포 변화 구분: Δln n(r_i) = a₀ + a₁ψ(r_i) + ε_i 최소제곱 (ψ = +½ 중앙, −½ 가장자리).
- 제어 출력은 FHP가 직접 재는 R_Γ, R은 T_e로 환산해 보고한다.
- J 측정: 동작점마다 총 전류 ±5%, 중앙 몫 ±0.05를 3회씩 (12회), 16 동작점 ≈ 190회, 3–4시간. 총 전류 열은 P ∝ I²(가정)로 ln P 기준으로 바꿔 계산값과 비교한다.

## 근거
- 점별 잡음 2%(가정)면 ln R_Γ 불확도 ≈ 1.1%, R로 환산하면 T_e 오차 5%(가정)에서 ≈ 3.7%.
- FHP는 교류 측정이라 어느 정도 증착되어도 측정되고 잡음에 강하다(교재 5장).
- 랭뮤어 탐침 면적은 교재 예대로면 접지 금속면의 약 1/40,000, Ar이면 약 1/27,000보다 작아야 한다(식 5.1).
- 코일 전류를 고정한 채 남는 R 변화로 회로 결합과 플라즈마 결합을 나눌 수 있다(H3).

## 고려한 대안
- 랭뮤어 탐침만 (기각: 느림, 교란).
- OES + 아벨 역변환 (보조 지표로만).

## 결과와 부작용
FHP가 재는 것은 이온 선속이라 R_Γ와 R 사이에 T_e 환산이 필요하다 (ADR-001의 R_Γ 제어와 연결). 웨이퍼형 배열이 없으면 이동식 FHP 반복 측정으로 대신하고 시간이 늘어난다.

## 틀렸을 때 확인하는 방법
컷오프 탐침 교정(V3), 랭뮤어 EEPF로 맥스웰 가정 확인(위험 등록부 5번).
