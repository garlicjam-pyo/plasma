# ADR-006 · 제어 구조와 운전 절차 — 전류 안쪽 루프 + 웨이퍼 측정 바깥 루프, J⁻¹ 피드포워드

- **상태**: 채택
- **날짜**: 2026-11-05 (1차 발표)
- **확신도**: 높음
- **관련**: 상세설계보고서 결정 6, `docs/조정절차.md`, 백로그 B06·B14

## 맥락
플라즈마 밀도 응답(입자 손실 시간 τ_p ≈ 90–200 μs, 10–30 mTorr)은 정합기·센서(0.1–1 s)보다 세 자릿수, 코일 전류 루프(ms 이하)보다 한 자릿수 정도 빨라 정적 이득 J로 다룰 수 있다. VI 프로브 전력 측정은 위상 오차에 민감하다(교재 식 5.33: 교재 예 tan φ_Z ≈ 100에서 위상 0.1°에 전력 17%, 설계 코일 tan φ_Z ≈ 20에서도 0.1°에 약 3.5%).

## 결정
- 세 겹 루프: 코일 전류·위상(ms 이하) / 자동 정합(0.1–1 s) / 웨이퍼 측정으로 n̄·R_Γ(ω_c ≤ 0.2 rad/s ≈ 0.032 Hz, 설정 시간 ≈ 20 s).
- 안쪽 루프는 전력이 아니라 코일 전류의 크기와 위상을 기준으로 한다.
- 단계 변경은 J⁻¹ 피드포워드(Δx = Δln R*/J₂₂, Δln P = (Δln n̄* − J₁₂Δx)/J₁₁)로 한 번에, 피드백은 잔여 오차와 드리프트만.
- RGA λ₁₁ ≈ 1이므로 (총 전력 → n̄), (분배 x → R)의 두 단일 루프로 나눈다.
- 정착 판정은 |Δln R_Γ| ≤ 0.02, n̄ 변화 ±5% 안, 60 s 안 수렴. 절차 6단계와 실패 조건·복구 동작은 `docs/조정절차.md`.

## 근거
- 위상 여유 PM = 90° − ω_c T_d·180°/π ≥ 60° ⇔ ω_c ≤ π/(6T_d). T_d = 1–2 s면 ω_c ≤ 0.26–0.52 rad/s이고, 정합기보다 5배 이상 느리게 두면 0.2 rad/s다.
- 20 mTorr 설계 형상에서 J₁₁ = 1, J₁₂ = 0.25, J₂₁ = 0, J₂₂ = 2.44 (계산, ln P 기준). R을 ln 기준 0.2 낮추려면 Δx = −0.082, Δln P = +2.1%. 보상하지 않으면 n̄가 2.1% 내려간다.
- J₂₁ = 0은 "T_e가 전력과 무관"이라는 모델 가정의 귀결이다(H4로 확인). 수동 공진(A)도 λ₁₁ = 1.04–1.09라 결합보다는 공진 근처의 이득 급변(비선형)이 문제다.

## 고려한 대안
- 전력 기준 안쪽 루프 (기각: 위상 오차 민감).
- 2×2 다변수 제어기 (불필요: RGA ≈ 1).
- 안테나 3개 이상으로 빠른 과도 응답 (기각: 조건수 증가로 오히려 느려짐).

## 결과와 부작용
바깥 루프가 느려 수 초 이하 레시피 단계나 펄스 운전에서는 피드포워드 표의 정확도가 성능을 정한다(B14). 이득 스케줄링 표(압력 5개 × 전력 2개 × 위상 2개 = 20 동작점)를 V1이 만든다. 분배 한계는 코일 선택도 때문에 중앙 몫 약 0.07/0.93이다.

## 틀렸을 때 확인하는 방법
가설 H7 (R 설정값 0.8/1.0/1.2 계단 응답). 정합기·전원 응답 시간 사양 확인 (위험 등록부 10번).
