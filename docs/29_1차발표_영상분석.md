# 29. 1차 발표 녹화 영상 분석

작성 2026-11-26. 녹화 영상(14분 16초)을 영상 프레임과 슬라이드 대조(1초 간격), 자동 자막(Whisper large-v3-turbo, sherpa-onnx), 음성 구간 검출(Silero VAD), 음량 측정(EBU R128)으로 분석했다. 자막은 기호와 전문 용어에서 틀릴 수 있어, 발음에 관한 내용은 표시한 시각에서 직접 들어 확인해야 한다. 영상과 자막 원문은 개인정보가 있어 저장소에 넣지 않는다.

## 요약

영상은 14분 16초지만 10쪽을 두 번 읽은 86초가 들어 있어, 중복을 빼면 12분 50초다. 3–15쪽은 대본을 빠짐없이 읽었고, 모자란 시간은 대부분 말 속도(대본 계획의 약 1.4배)에서 왔다.

- 꼭 고칠 것: 6분 59.9초–8분 26.0초의 중복 구간 삭제 (편집만으로 가능)
- 빠진 내용: 2쪽 교수님 코멘트를 "넘어가겠습니다"로 지나가, 피드백 여섯 가지의 반영이 말로는 전달되지 않음
- 다시 녹화할지는 길이 기준에 달림: 20분을 채워야 하면 다시 녹화, 20분 이내면 중복만 잘라 제출 가능

## 고칠 것

편집만 할 때 (20분 이내가 기준일 때):

1. 6:59.9–8:26.0을 자른다(86초). 앞뒤 모두 무음이고 화면도 10쪽이라 이음매가 보이지 않는다. 길이는 12분 50초. 처음 읽은 쪽을 남기려면 8:10.8–9:36.2를 자른다(85초).
2. 2쪽에 대본 70초(또는 30초 요약)를 따로 녹음해 넣는다.
3. 음량을 −16 LUFS 안팎으로 올리고, 끝에 END 화면을 1–2초 더 둔다.

다시 녹화할 때 (20분을 채워야 할 때):

1. 대본 시각표대로 분당 250자 안팎으로 읽는다. 지금 속도로는 대본 전체를 읽어도 약 13분 40초다.
2. 2쪽 대본을 읽는다.
3. φ는 "파이", ψ는 "프사이", ρ는 "로우". 7쪽 "φ + ψ"는 "파이 플러스 프사이".
4. 슬라이드 쇼를 전체 화면으로 띄우고 녹화한다.
5. 끝난 뒤 한 번 돌려 보며 중복 구간이 없는지 확인한다.
