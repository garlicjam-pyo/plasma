## 3. 판정과 조건

- **B 채택.** 핵심 기준 ②(독립성)에서 앞서고, 분배를 공진점이 아니라 두 전원의 설정값으로 정한다. 비용은 전원·정합기 1벌 추가.
- **A는 독립성(L1) 때문에 기준에서 뺀다. 전원이 1대뿐일 때의 대안으로 남긴다.** 범위 때문이 아니다(KC20은 고압에서 R < 1을 보였다). 전원이 1대뿐이면 L1을 감수하고 A로 돌아간다 (위험 등록부 7번).
- **C 선택 사항.** 15 mTorr 아래 운전이 필요할 때만 더한다. 자석 전류는 빠른 조작 변수가 아니라 J의 모양을 바꾸는 손잡이로, 압력별 고정값(피드포워드 표)으로 둔다.
- **D 보류.** 가설 H6(0° vs 180°)에서 두 위상이 모두 불리할 때 재검토한다.

## 4. B 안의 위상: 0° 기준, 180° 비교

교환 전력 P_exch = (ωM₁₂ + X′₁₂)·k·|I₁|²·sin φ는 90°에서 흡수 전력의 0.2–0.7배라(계산, X′₁₂ ≈ −4 ~ −6 Ω 포함) 위상을 연속 손잡이로 쓰지 않고 0°나 180° 근처에 고정한다. 아래 수치는 단일 턴·균일 반공간·고정 밀도 계산(n = 3×10¹⁰–10¹¹ cm⁻³, 10–20 mTorr, 중앙 전력 몫 0.20)이라 "0°·180° 한정"의 확신도는 중간이다.

| 항목 | 0° | 180° | 유리 |
|---|---|---|---|
| R ≈ 1 전류비 k = I₂/I₁ | 2.0–2.1 | 0.83–1.03 | 180° |
| 같은 전류에서 흡수 전력 (90° 대비) | 1.22–1.27배 | 0.49–0.67배 | 0° |
| 300 W에서 코일 전류 I₁ / I₂ | 3.4 A / 6.6–7.3 A | 8–12 A / 8–10 A | 0° |
| 효율 η (두 코일 0.23 Ω 가정) | 0.95–0.96 | 0.85–0.91 | 0° |
| 경계 ±3 cm 띠 흡수 몫 | 0.34–0.35 | 0.20–0.22 | 180° |
| 분배 이득 ∂ln(P_c/P_e)/∂ln k (전류비 오차도 같은 배율로 커짐) | −0.8 ~ −1.0 | −2.9 ~ −4.0 | 180° |
| 분배의 밀도 의존 (전류 고정) | −0.10 ~ −0.01 | +0.41 ~ +0.73 | 0° |
| 교환 전력 ≤ 10% 위상 허용 오차 | ±19–38° | ±4–12° | 0° |
| 안쪽 코일 리액턴스 변화 (X′₁₂ 포함, 괄호는 코일 항만) | +13–24% (+47–51%) | −7–10% (−20–25%) | 180° |
| 바깥 코일 리액턴스 변화 (X′₁₂ 포함, 괄호는 코일 항만) | +1–2% (+5%) | −3–6% (−10–13%) | 둘 다 작음 |

- 180°의 "분배 이득 3–4배"는 R 범위가 넓다는 뜻이 아니라 같은 전류비 변화에 분배가 더 크게 움직인다는 뜻이다. 전류비 오차도 같이 커진다.
- 0°의 부담은 바깥 코일 전류가 안쪽의 약 2배라는 점이지만, 같은 300 W에서 절대 전류는 180°보다 작다.

180° 채택 조건(H6): 분배 이득이 0°의 2배 이상 **그리고** 누설 0.2 이하 **그리고** 위상 허용 오차(±4–12°) 안에서 운전 가능.
