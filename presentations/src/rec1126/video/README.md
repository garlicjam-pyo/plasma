# 1차 녹화 영상 편집 (18분판)

영상 원본과 자막은 개인정보가 있어 저장소에 넣지 않는다. 순서:

1. `asr.py audio16k.wav full.json` — Silero VAD로 말한 구간을 찾고(`full_vad.json`), Whisper large-v3-turbo(sherpa-onnx)로 받아 쓴다.
2. `plan_map.py` (v1) / `plan_map2.py 1.15` (v2, 지금 판) — 중복 구간(419.9–506.0 s)을 빼고, 말한 구간 ×1.25(0.8배속), 쉼 ×g(최대 5 s)로 늘려 18:00이 되는 g를 찾는다(`map.json`, g ≈ 1.99).
3. `stretch_audio.py` — 말한 구간은 Rubber Band(R3, 음색 유지)로 늘리고, 쉼은 가장 조용한 지점에 무음을 넣어 늘린다. 끝에 2 s.
4. 영상은 같은 지도로 `select`(중복 제거) + `setpts`(구간별 선형 사상) + `fps=30` + `tpad`(END 2 s)로 만들고, 음량은 +3.2 dB와 리미터로 −16 LUFS에 맞춘다.

검증: 출력 1080.0 s, −16.0 LUFS. 출력 영상의 쪽 전환 시각이 지도에서 계산한 값과 ±1 s 안에서 일치하고, 잘라낸 곳 앞뒤 자막이 이어지며 중복이 없다.

v2 (2026-11-26): 말은 덜 늦추고 쉼을 더 늘렸다. `plan_map2.py 1.15` — 말한 구간 ×1.15(0.87배속), 0.5 s 미만 짧은 숨 ×1.3, 문장 사이 쉼 ×g(≈2.53, 최대 6 s), 쪽 전환 쉼은 최소 3 s. 이음매마다 3 ms 페이드. 출력 1080.0 s, −16.0 LUFS(최고 −1.5 dB), 쪽 전환 시각 ±2 s 안에서 일치.
