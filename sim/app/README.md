# app — 독립 제어 GUI

원하는 평균 밀도와 밀도비를 정하면 그것을 만드는 전력과 전류비를 찾아 주고, 세 입력을 직접 바꿔 가며
시뮬레이션도 할 수 있는 화면이다. 계산은 `sim/hybrid/` 모델이 한다.

## 실행

```bash
python -m pip install -r requirements.txt   # numpy, scipy, matplotlib (처음 한 번)
python sim/app/server.py                    # http://localhost:8765 가 브라우저에 열린다
python sim/app/server.py --port 9000 --no-browser
```

추가 설치는 없다. 서버는 파이썬 표준 라이브러리, 화면은 순수 HTML·CSS·JS 다(인터넷 연결 불필요).
기본값은 이 컴퓨터에서만 접속할 수 있게 127.0.0.1 로만 연다. `--host 0.0.0.0` 을 주면 같은 네트워크의 다른 컴퓨터도 접속한다(로그인 절차 없음).

## 구성

| 구분 | 파일 | 역할 |
| --- | --- | --- |
| 백엔드 | `server.py` | HTTP 요청을 받아 정적 파일을 주거나 `/api/*` 를 service 로 넘김 |
| 백엔드 | `service.py` | 요청 → 모델 설정, 계산, 결과 → JSON. 가까운 해를 기억해 다음 계산의 출발점으로 씀 |
| 모델 | `../hybrid/inverse.py` | 목표 (n̄_w, ρ) → 입력 (P_tot, k) 를 찾는 역문제 풀이, 도달 가능 영역 |
| 프론트엔드 | `web/index.html`, `web/style.css` | 화면 구조와 모양 |
| 프론트엔드 | `web/js/api.js` | 백엔드 호출 |
| 프론트엔드 | `web/js/app.js` | 상태와 동작 (조작 → 요청 → 다시 그리기) |
| 프론트엔드 | `web/js/chamber.js`, `charts.js`, `draw.js` | 챔버 단면, 그래프, 목표 선택 판 그리기 |

다른 컴퓨터에 설치하거나, 한 컴퓨터에서 켜고 같은 네트워크의 다른 컴퓨터에서 접속하는 방법(`--host 0.0.0.0`),
문제 해결은 `docs/24_GUI_설치_접속_안내.md` 에 있다. 설계 선택의 이유는 `docs/25_모델과_코드_설명.md`.

## 화면

- **목표로 맞추기**: 판 위의 표적을 끌어 평균 밀도(가로)와 밀도비(세로)를 정하고 손을 떼면, 위상차를 고정한 채
  전력과 전류비를 찾는다. 옅은 보라 영역이 그 압력·위상에서 도달할 수 있는 범위이고, 검은 선이 맞춰 간 걸음이다.
  풀이는 바깥 제어 루프와 같은 꼴(오차 → J⁻¹ → 입력 보정)이며 보통 수렴 계산 6–9회, 1초 안팎이다.
  이 빠른 풀이가 닿지 못하면 전류비 전 범위(0.05–5)를 훑어 다시 찾는다(2–8초). φ = 180° 에서는 밀도비가 전류비에 대해
  단조가 아니어서 이 단계가 필요하다. 목표가 범위 밖이면 낼 수 있는 밀도비 범위를 알려 주고 가장 가까운 값으로 맞춘다.
  탐색 범위(전력 30–1500 W, 전류비 0.05–5)는 `hybrid/inverse.py` 에 있고 슬라이더 범위도 그 값을 따른다.
- **직접 조정**: 총 전력, 전류비, 위상차 슬라이더를 움직이면 바로 다시 계산한다(운전점당 약 0.1 s).
  "제어 민감도 계산"은 그 운전점의 J_ctrl 을 보여 준다.
- **운전 조건**(두 방식 공통): 압력, 코일 구성(이중 / 단일), 계산 모델(반경 1D / 2D 수송).
- **결과**: 챔버 단면(전자 밀도, 흡수 전력, 전기장, 전자온도 중 선택), 평균 밀도와 밀도비, 웨이퍼 위 밀도 분포
  (직전 결과와 겹쳐 보임), 전자온도와 가열 분포.
- **구동부 값**: 전원별 전력과 코일 전압(진폭). 위상차가 있으면 상호 결합으로 전력이 한 전원에서 다른 전원으로 넘어가
  한쪽이 음수가 될 수 있다. 그때는 독립 전원 2대로 만들 수 없는 조건이라는 경고가 뜬다.
- 전력이 너무 낮거나 두 코일의 장이 상쇄되는 조건(예: 3 mTorr, 30 W, 180°)에서는 모델의 방전이 유지되지 않아
  "수렴하지 못함"이 표시된다. 그때의 숫자는 의미가 없다.

단일 코일을 고르고 목표로 맞추기를 하면 평균 밀도만 맞고 밀도비는 맞지 않는다(입력이 전력 하나뿐).

## API

| 요청 | 본문 | 응답 |
| --- | --- | --- |
| `GET /api/meta` | | 조절 범위, 기본값, 챔버 형상 |
| `POST /api/simulate` | `P_tot, k, phi_deg, p_mtorr, coil_mode, transport` | 지표, 코일 전류, 분포, (r, z) 지도 |
| `POST /api/control` | 위 항목 + `n_target [m^-3], rho_target` | 성공 여부, 설명, 걸음별 궤적, 마지막 결과 |
| `POST /api/reachable` | `phi_deg, p_mtorr, transport` | (n̄_w, ρ) 평면의 위·아래 경계 |
| `POST /api/jacobian` | 운전점 | J_norm, 계수, 조건수, 형상 감도 |

모델 가정(국소 Maxwell 분포, 유체 수송)과 그 민감도는 `sim/hybrid/README.md` 에 있다. 화면의 값은 그 모델 안에서의 결과다.
