# 18. 수식 흐름과 최종 목표(Δn̄_w = 0, Δρ ≠ 0)의 연결

식 번호는 팀 이론 정리 개정 3을 따른다.

## 한 줄 흐름

운전 입력 (9.1) → 코일 장과 흡수 전력 (1.10), (1.4), (1.13) → 두 경로 → 웨이퍼 면 (W1)–(W2) → 감도 행렬 J (9.2) → 판정 (9.3)

## 두 경로

| | 수준 경로 → n̄_w | 모양 경로 → ρ |
| --- | --- | --- |
| 입력 | 총 흡수 전력 P_abs (주로 P_tot) | 가열 모양 p_abs/P_abs (주로 k, φ) |
| 1단계 | 입자 균형 (T1)의 적분이 T_e 수준을 정함 | 에너지식 (M1)–(M4)이 가열 모양을 λ_ε로 평활해 δT_e를 만듦 |
| 2단계 | 전력 균형 (M7)이 밀도 진폭 n̄ ∝ P_abs를 정함 | 국소 Maxwellian (M2), (M3)이 δT_e를 이온화 차이로 약 7배 증폭 |
| 3단계 | | 양극성 확산 (Γ2), (Γ3)이 생성 모양을 ℓ_r로 다시 평활해 n 모양을 만듦 |
| J에서의 위치 | 1행 (∂n̄_w/∂u) | 2행 (∂ρ/∂u) |

- 모양 경로는 평활(λ_ε) → 증폭(×7) → 평활(ℓ_r)의 세 단계를 거친다. 그 결과 남는 전달률이 R(k)다(`17_0D_독립제어_가능성.md`). 10 mTorr, 반경 2차 모드에서 R ≈ 0.20이다.
- 이 중 국소 Maxwellian은 증폭 단계다. "가열 모양"이 "이온화 모양"으로 바뀌는 곳은 이 단계 하나뿐이다.
- 되먹임도 있다. n과 T_e는 σ_p(ν_m)를 거쳐 장 단계 (S1–S3)로 돌아간다. 이 반복을 (F1)–(F2)로 수렴시키고 (F3)–(F5)로 점검한다.

## 두 경로가 완전히 갈라지지 않는 곳 (J의 비대각 성분)

1. **효율:** k와 φ를 바꾸면 회로 효율 η = P_abs/P_in이 달라진다. 그래서 수준 경로로 새어 들어간다(KC20의 1 mTorr 결과).
2. **웨이퍼 가중:** n̄_w는 웨이퍼 영역의 면적 평균이다. 그래서 모양이 바뀌면 n̄_w도 함께 바뀐다(W2).
3. **볼록성:** T_e 분포가 고르지 않으면 같은 평균 T_e에서도 평균 이온화가 커진다. 그만큼 T_e 수준이 조금 내려간다(16번 문서 4절).

J를 대각 행렬로 가정하지 않고 직접 계산해야 하는 이유가 이 세 가지다.

## 결국 구하는 것

(9.3)은 다음 질문과 같다. "k, φ로 가열 모양을 바꿀 수 있는 폭 × 전달률 R"이 입력 한계 안에서 원하는 Δρ를 만드는가? 이때 위의 새는 성분은 P_tot으로 보정한다.

- 전달률 R은 압력이 정한다. 10 mTorr에서 0.20, 30 mTorr에서 0.53이다.
- 모양을 바꿀 수 있는 폭은 장 계산(1.10)과 회로(1.13)가 정한다.
