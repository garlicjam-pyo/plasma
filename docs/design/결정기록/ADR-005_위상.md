# ADR-005 · 두 전원의 위상 — 0° 기준, 180° 비교 조건

- **상태**: 채택 (팀 원안 180°에서 변경, H6에서 재판정)
- **날짜**: 2026-11-05 (1차 발표)
- **확신도**: 중간 (계산 가정에 민감). "0°·180° 근처에 고정"도 중간
- **관련**: 상세설계보고서 결정 5, `sim/two_source_phase.py`, `sim/presentation1_estimates.py phase`, 백로그 B02·B18

## 맥락
팀은 처음 180°(역상)를 계획했다. 두 전원이 같은 주파수이면 상호 인덕턴스와 플라즈마를 통해 한 전원이 다른 전원으로 밀어 넣는 교환 전력 P_exch = (ωM₁₂ + X′₁₂)·k·|I₁|²·sin φ가 생긴다. 플라즈마 상호 리액턴스 X′₁₂ ≈ −4 ~ −6 Ω이 ωM₁₂ = 7.75 Ω을 상당 부분 상쇄한다.

## 결정
- 공통 발진기로 위상을 고정하고 기준값은 0°, 비교 조건은 180°.
- 위상을 연속 조작 변수로 쓰는 안은 기각 (90°에서 교환 전력이 흡수 전력의 0.2–0.7배).
- 180° 채택 조건(H6): 분배 이득이 0°의 2배 이상, 누설 0.2 이하, 위상 허용 오차(±4–12°) 안에서 운전 가능.

## 근거
단일 턴·균일 반공간·고정 밀도 계산(n = 3×10¹⁰–10¹¹ cm⁻³, 10–20 mTorr, 중앙 전력 몫 0.20).

| 항목 | 0° | 180° |
|---|---|---|
| 교환 전력 ≤ 10% 위상 허용 오차 | ±19–38° | ±4–12° |
| 효율 η (두 코일 0.23 Ω) | 0.95–0.96 | 0.85–0.91 |
| 300 W에서 I₁ / I₂ | 3.4 A / 6.6–7.3 A | 8–12 A / 8–10 A |
| 분배의 밀도 의존 (전류 고정) | −0.10 ~ −0.01 | +0.41 ~ +0.73 |
| 분배 이득 ∂ln(P_c/P_e)/∂ln k | −0.8 ~ −1.0 | −2.9 ~ −4.0 |
| 경계 ±3 cm 띠 흡수 몫 | 0.34–0.35 | 0.20–0.22 |
| 안쪽 리액턴스 변화 (X′₁₂ 포함, 괄호는 코일 항만) | +13–24% (+47–51%) | −7–10% (−20–25%) |
| 바깥 리액턴스 변화 (X′₁₂ 포함, 괄호는 코일 항만) | +1–2% (+5%) | −3–6% (−10–13%) |

- 0°가 앞서는 것: 독립성(분배의 밀도 의존이 작아 전력 열 누설 g_R × 0.10 ≤ 0.09, 180°는 0.2–0.6, 추정), 위상 허용 오차(2–5배 넓음), 효율, 같은 전력의 코일 전류.
- 180°가 앞서는 것: 경계 띠 분리(0.34 → 0.21), 정합 리액턴스 변화(작음), 분배 이득. 분배 이득 3–4배는 R 범위가 넓다는 뜻이 아니라 같은 전류비 변화에 분배가 더 움직인다는 뜻이고, 전류비 오차도 같이 커진다.
- P_exch = 0인 것은 sin φ = 0인 0°·180°이므로 그 근처에 고정한다.

## 고려한 대안
- 180° 기준 (보류: H6에서 같은 기준으로 비교).
- 연속 위상 (기각: 교환 전력, 과도 때 역전력).
- 다른 주파수 2대 (보류: ADR-004의 D).

## 결과와 부작용
- 0°에서 R ≈ 1을 만들려면 바깥 코일 전류가 안쪽의 약 2배다. 다만 같은 300 W에서 코일 전류는 180°가 더 크다(위 표). 처음에 적은 "0°의 부담은 바깥 코일 전압"은 거꾸로였다.
- 처음 계산은 ωM₁₂만 써서 교환 전력을 2–4배 크게, 위상 허용 오차를 좁게 보았다(2026-11-05 검토 3번, `07_검토결과_2026-11-05.md`). 위 표가 X′₁₂를 넣어 다시 계산한 값이다.
- 수치는 단일 턴·균일 반공간·고정 밀도 계산이라 V1에서 다중 턴과 자기일관 밀도로 다시 계산한다. sin φ 결론과 "같은 전류에서 180°의 흡수 전력이 작다"는 결론은 교차 저항 R′₁₂ > 0인 한 유지된다.
