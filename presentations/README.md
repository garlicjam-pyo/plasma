## 다시 만들기

```bash
python -m pip install python-pptx
python presentations/src/build.py presentations/template/발표양식_4x3.pptx presentations/1차발표_최종.pptx
```

개정본 두 판은 `python presentations/src/revision/build.py` (수식 `src/revision/eq/mk.py` → `NODE_PATH=/opt/npm-tools/node_modules node render.js`, 그림 `src/revision/fig/figs.py`).

수식을 고치면 `src/eq/eqs.json`을 바꾸고 `node render.js`로 PNG와 `sizes.json`을 다시 만든다 (katex, playwright 필요).

## 양식 사용 규칙 (1차 발표에서 정한 것)

- 레이아웃: 표지는 `제목 슬라이드`, 본문은 `제목만`. 제목은 한 줄(28 pt), 제목 아래 파란 선 밑에 구분 줄(12 pt)을 둔다.
- 본문 글자는 12 pt 이상, 각주만 10 pt. 쪽 번호는 바닥글 오른쪽.
- 본편 슬라이드 형식: 구분 줄은 `장 · 이 쪽의 역할 · (제출물/검토 사항)`, 본문은 제목 아래 1.42–5.75 in 안, 그 아래 핵심 메시지 한 줄(→, 5.88 in)과 출처·계산 조건만 담은 각주 한 줄(6.47 in). 표지·목차·참고문헌은 핵심 메시지 없음.
- 팀 질문 번호(질문 x-x)는 백업 B7 대응표와 백업 슬라이드에만 쓴다.
- 색의 뜻: 파랑 = 중앙·안쪽 코일, 주황 = 가장자리·바깥 코일, 남색·양식 제목색 = 구조·결론, 호박색 = 한계·누설·주의. 바탕은 흰색·옅은 회색만 쓴다.
- 학회 발표 스타일(11-06): 모서리는 각지게, 내용 블록은 흰 바탕 + 얇은 테두리 + 위쪽 색 선, 표는 booktabs식(머리 채움 없음, 위·아래 굵은 선), 번호는 원 대신 굵은 숫자, 식 번호는 (1a) 꼴, 결론 한 줄은 채운 상자·화살표 없이 위쪽 선 + 굵은 글씨, 구분 줄은 회색. 큰 숫자 카드 대신 표로 값을 보인다.
- 차트는 PowerPoint 기본 차트로 넣어 편집할 수 있게 한다. 목표 범위(R 0.8–1.2)는 옅은 회청색 띠로 통일.
- 수치 옆 표시: (계산) / (추정) / (가정).
- 설계 포함판(`1차발표_최종.pptx`): 교재 장·식 번호는 슬라이드에 쓰지 않고, 공식을 슬라이드 안에서 직접 보여 주며 덱 안의 번호(식 1–7)로 앞뒤를 잇는다.
- 이론 배경판(`1차발표_이론배경판.pptx`, 11-09부터): 이론식은 수업 교재(정진욱, 『플라즈마 전자공학』 4판, 교문사, 2026)를 각주에 절·쪽·식 번호로 우선 인용하고, Lieberman & Lichtenberg(2005)는 교재에 없는 내용과 교차 대조에만 쓴다. 그림·수치의 직접 출처는 해당 논문으로 적는다. 교재 원식과 팀 확장(영역별 평형식, 두 코일 2포트 등)은 구분해 표시한다. 발표자 노트는 `[대본 · 시각 / 초]`와 `[근거(읽지 않음)]`로 나눈다.
