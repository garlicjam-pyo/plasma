# 10. 후속 프로젝트 계획 (1차 발표 이후)

작성 2026-11-06. 근거: 커밋 `8be3989`에 대한 외부 검토와 저장소의 코드·문서를 다시 확인한 결과. 기존 일정(`03_작업계획.md` 4절)은 원안으로 남기고, 이 문서의 일정이 그것을 대신한다.

## 1. 요약

다음 단계의 첫 과제는 "독립 제어를 했다"고 판정하는 방법을 바로 세우는 것이다. 지금 절차로는 중앙과 가장자리 밀도가 둘 다 크게 변해도 시험을 통과할 수 있다.

1차 발표와 설계 초안은 끝났고, 주요 계산은 다시 돌려도 같은 값이 나온다. 외부 검토가 지적한 문제는 네 갈래다.

- **판정 기준:** 평균 밀도를 유지하는 시험만 있고, 한쪽 영역을 유지하는 시험은 없다.
- **판정 대상:** 모델, 센서, 보고서가 서로 다른 밀도비(R, R_Γ, 집계 반경)로 합격을 매긴다.
- **분석 코드:** 독립 조작이 불가능한 입력에도 L1을 출력한다.
- **모델 검증:** KC20 대조가 뒷받침하는 범위는 비공진 급전 전류까지다. 밀도 분포는 아직 검증하지 못했다.

그래서 작업 순서는 다음과 같다.

1. 재현 환경과 발표 표기 정비
2. 판정 기준 통일
3. 한쪽 유지 시험과 회귀 판정 수정
4. 같은 공간 범위에서 KC20 재비교와 모델 보정
5. 압력·위상별 J 재계산 (V1)
6. 축대칭 2D 계산 (V2)
7. 2차 발표

지금 방어할 수 있는 결론은 여기까지다. 독립 RF 전원 2대와 0° 위상을 다음 검증의 기준 설계로 삼을 근거가 있고, 시험할 압력대는 20–30 mTorr다. 실제 웨이퍼 위치에서 R 0.8–1.2를 독립적으로 따라가는지는 이 계획이 답할 질문이다.

## 4. 단계별 계획

일곱 단계(P0–P6)로 나눈다. 판정 기준(P1)과 회귀 코드(P2)를 먼저 고쳐야 V1 계산(P4)의 결과를 합격·불합격으로 읽을 수 있다. 그래서 기존 일정의 V1 앞에 이 두 단계를 넣었다.

### P0 정비 (W0)

목표: 누가 받아도 같은 결과가 나오고, 1차 발표가 주장하는 범위를 넘지 않게 한다.

1. `requirements.txt`를 `numpy>=2.0`으로 올리거나, 1.x용 적분 함수를 둔다. 새 가상환경에서 검증·발표 스크립트를 다시 돌린다.
2. 발표 24쪽 제목을 “목표 밀도비의 우선 검증 압력은 20–30 mTorr”로 바꾼다. 26·40쪽 제목도 한 줄로 줄인다.
3. 15쪽 각주에 ±9%가 비공진 급전 전류 값이고, 공진 R은 문헌 0.39 대 모델 5.17이라고 적는다.
4. PR #1(문헌 목록)을 병합하고, `topic/two-zone-model` → `main` PR을 연다. 병합 시점은 팀이 정한다.

완료 기준: 깨끗한 환경에서 CSV가 저장본과 같고, 발표 수정본이 PowerPoint에서 한 줄 제목으로 보인다.

### P1 판정 기준 통일 (W1 전반)

목표: 모델, 센서, 보고서가 같은 양을 같은 위치에서 같은 기준으로 판정하게 한다.

1. 합격표 하나를 만든다. 항목마다 무엇을(R_Γ 또는 환산 R), 어디서(중앙 r ≤ 25 mm, 가장자리 135–140 mm, 웨이퍼 높이), 어느 설정값과 비교하는지 적는다.
2. 설정값 R을 R_Γ로 바꾸는 규칙을 정한다. 검토가 계산한 0.757 / 0.959 / 1.161(20 mTorr·300 W)을 우리 모델로 재현한다. 환산 R에는 ±3.7% 불확도를 붙인다.
3. 시험을 세 가지로 정의한다. T1은 n̄ 유지(기존 H7), T2는 중앙 고정·가장자리 변경, T3는 가장자리 고정·중앙 변경이다. 유지 영역의 허용치는 제안값 |Δln Γ| ≤ 0.02에서 출발해 팀이 정한다.
4. 평균의 정의를 하나로 정한다(체적 가중 n̄ 권장). 모델, 회귀, 절차가 같은 정의를 쓴다.
5. `06`의 에너지 균형식을 코드가 쓰는 식(이온화·벽 손실·영역 간 에너지 이동)으로 바꾼다.

산출물: 판정 기준 문서와 ADR-009, `06`·`측정계획.md`·`조정절차.md` 갱신. 완료 기준: 세 문서와 발표 백업 B7이 같은 합격표를 가리킨다.

### P2 한쪽 유지 시험과 회귀 판정 (W1)

목표: 검토 사항 3에 직접 답하고, 독립성 판정이 틀린 입력에서 통과하지 않게 한다.

1. 조정 절차에 T2·T3을 넣는다. 출력을 (ln n_c, ln n_e)로 바꾼 J를 쓰면 한쪽을 고정하는 조작을 바로 풀 수 있다.
2. `sim/jacobian_fit.py`가 등급을 매기기 전에 행렬의 계수와 최소 특잇값을 측정 불확도와 비교하게 한다. 기준을 못 넘으면 “L0 또는 판정 불가”를 출력하고, RGA 무한대도 처리한다.
3. a₀를 P1의 평균 정의로 바꾼다. 등가중과 체적 가중 값을 함께 출력한다.
4. 합성 입력 세 가지로 시험한다: 특이 행렬 [[1, 1], [1, 1]], 대각 행렬, 20 mTorr 모델 J.

완료 기준: 특이 행렬은 L0, 대각 행렬은 L2로 나온다. 분배 누설비는 두 평균 정의로 함께 보고되고, 0.104와 0.244의 차이가 설명된다.

### P3 KC20 재비교와 모델 보정 (W1–W2)

목표: 모델을 밀도비 판단에 어디까지 쓸 수 있는지 정한다.

1. 문헌 분포와 모델을 같은 반경 구간으로 집계해 다시 비교한다. 지금은 같은 데이터도 넓은 영역이면 1.05, 설계 구간이면 0.19다.
2. 공진 상태 재현을 보정한다(백로그 B19). 원인 후보는 전력 분배 방식, 표피층 밀도 정의, 비국소 브리지, 공진점 위치다. 하나씩 바꿔 본다.
3. 비교표를 급전 전류, 공진점, 같은 구간의 R로 나눠 적는다.

완료 기준(관문 G1): 공진 R의 방향이 문헌과 같고 크기가 0.5–2배 안이면 모델로 R을 판단한다. 못 맞추면 모델 사용 범위를 “독립 전원의 경향”으로 제한하고 보고서에 적는다.

### P4 압력·위상별 재계산, V1 (W2–W3)

목표: 통일된 입력과 합격표로 J(p, φ)를 만들고 가설을 1차 판정한다.

1. 브리지 거리를 설계값 7.5 cm로 맞춘다. 영역 전력은 챔버 안 체적 소산 기준과 창 표면 기준을 둘 다 계산해 민감도를 본다.
2. 5–30 mTorr × 0°/180° × 300/600 W에서 J, R 범위, 정합 위치를 계산해 이득 스케줄링 표를 채운다.
3. 위상 비교 절차에 전류비를 다시 설정하는 순서와 전원별 역전력 허용치를 넣는다.
4. T1–T3을 모델로 돌리고, H1·H3·H4·H6·H7을 1차 판정한다.

완료 기준(관문 G2): 압력별 R_min과 0°/180° 비교표가 갱신되고, 위상 기준과 운전 압력대를 팀이 확정한다.

### P5 축대칭 2D, V2 (W4–W5)

목표: 0D가 못 보는 공간 분포와 웨이퍼 위치의 값을 구한다.

1. 2D 확산과 장을 계산해 H2·H5를 판정한다.
2. 웨이퍼 높이의 측정 위치 환산 계수를 만든다.
3. P1 합격표와 같은 정의·위치로 R_Γ를 낸다.

완료 기준(관문 G3): 0D와 2D의 R 차이가 설명되고, 설계를 동결한다.

### P6 통합과 2차 발표 (W5–W6)

목표: 제출물 네 가지를 낸다.

1. 구성도, 조작 변수–밀도 응답 J(p, φ), T1–T3을 담은 조정 절차, 합격표를 담은 측정 계획을 확정한다.
2. 2차 보고서와 발표 자료를 만든다. 양식과 스타일은 1차와 같다.
3. 작업하지 않은 사람이 독립 검토를 한 번 한다.

완료 기준: 모든 주장이 합격표의 항목과 이어지고, 재현 스크립트로 같은 수치가 나온다.

2차 발표일은 아직 정해지지 않았다. 날짜가 정해지면 P6의 끝을 그 날에 맞추고 P5부터 거꾸로 다시 잡는다. 일정이 밀리면 아래 위험 표의 대응대로 P3 일부를 P4와 병행하고, P5에서 H5(선택)를 먼저 뺀다.

## 6. 팀 결정 사항과 위험

판정 기준 세 가지는 P1이 끝나는 11/15까지 정해야 P2–P4가 제때 시작한다.

| 결정 | 제안 | 기한 |
| --- | --- | --- |
| 판정하는 양 | 제어·판정은 R_Γ, R은 환산해 ±3.7%와 함께 보고 | 11/15 (P1) |
| 평균의 정의 | 체적 가중 n̄ | 11/15 (P1) |
| T2·T3 유지 영역 허용치 | \|Δln Γ\| ≤ 0.02 | 11/15 (P1) |
| 장비 | 전원 2대, 공통 발진기, FHP 배열을 쓸 수 있는지 확인 | 11/11 (P0) |
| `main` 병합 | P0 뒤 PR로 병합, 이후 단계별 PR | 11/11 (P0) |
| 2차 발표일 | 확정되면 일정을 역산 | 가능한 빨리 |
| 2D 계산 도구 | COMSOL 등, 사용 가능한 것 | 11/25 |
| 위상 기준 | 0° 기준, 180°는 H6 비교 | 12/2 (G2) |
| 운전 압력대 | 20–30 mTorr 우선, 15 mTorr는 경계 | 12/2 (G2) |

위험은 모델 신뢰도와 일정에 몰려 있다.

| 위험 | 알아차리는 신호 | 대응 |
| --- | --- | --- |
| 모델이 공진 R의 방향을 못 맞춘다 | G1에서 중앙·가장자리 중 조밀한 쪽이 문헌과 반대 | 모델은 독립 전원의 경향에만 쓰고, 판정은 비와 문헌으로 한다 |
| 압력대의 여유가 전력 분배 가정에 달렸다 | 두 분배 방식의 R_min 차이가 0.03을 넘는다 | 20–30 mTorr를 유지하고 15 mTorr는 조건부로 둔다 |
| T2·T3이 허용치를 못 맞춘다 | 유지 영역의 변화가 허용치를 넘거나 분배가 0.07–0.93 한계에 닿는다 | 압력을 올리거나 자기장 보조(H5)를 쓰고, 안 되면 목표 범위 조정을 제안한다 |
| 장비가 없어 V3를 못 한다 | P0 장비 확인 결과 | 문헌과 2D로 대신하고, 측정 계획은 설계안으로 낸다 |
| P1–P3이 V1을 밀어낸다 | 11/22까지 G1을 못 넘는다 | P3 일부를 P4와 병행하고, V2에서 H5(선택)를 뺀다 |
| 위상 전환 때 역전력이 생긴다 | 전원 포트 순전력이 음수(검토 계산 −25 W) | 전류비를 먼저 바꾼 뒤 위상을 바꾸고, 전원의 역전력 내성을 확인한다 |
