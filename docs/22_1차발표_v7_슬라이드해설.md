# 주제 3 1차 발표 v7 슬라이드별 해설

2026-11-11 작성. 원본: Claude 문서 「주제 3 1차 발표 v7 슬라이드별 해설」. 대상 덱: 팀 수정본 1차 발표 v7(본편 1–14장, 부록 15–21장 제외).

본편 14장(부록 15–21장 제외)의 내용과 화면 속 기호를 슬라이드 순서대로 함께 풀어 쓴 발표 준비용 해설이다. 기준 덱은 6조 1차 발표 v7이고, 교재 인용은 정진욱 『플라즈마 전자공학』 4판(교문사, 2026)의 절·쪽·식 번호를 따른다.

## 전체 흐름과 공통 표기 규칙

발표는 "평균 밀도는 유지하고 밀도비만 바꾼다"는 목표에서 출발해, 0D로는 판정할 수 없음을 보이고 2D 계산 절차와 판정법으로 닫힌다.

1. 목표 정의: 제어할 출력이 n̄\_w와 ρ 두 개다(2장).
2. 단일 코일: 입력이 P 하나라서 두 목표를 따로 맞출 수 없다(3장).
3. 이중 코일: 입력을 k, φ, P\_tot 셋으로 늘려도 0D에서는 P\_abs 하나로 합쳐진다(4장).
4. 0D의 세 한계: ρ 정의 불가, k와 φ 구분 불가, 균일 T\_e면 분포 모양 고정(5장).
5. 2D 모델: 계산 사슬의 각 단계가 세 한계에 하나씩 답한다(6장).
6. 2D 계산 절차: 초기값 → 전기장 → 흡수 전력 → 전자 에너지 → 입자 수송 → 반복 → 지표(7–12장).
7. 판정법: 여러 운전점의 감도 행렬로 형상 제어 자유도를 확인한다(13장).

### 공통 표기 규칙

## 슬라이드 1 · 표지

표지는 이번 발표가 결과 보고가 아니라 "이론적 배경"을 세우는 자리임을 정한다.

**화면 구성**

- 제목: 중앙·가장자리 플라즈마 밀도 독립 제어의 이론적 배경
- 부제: 플라즈마전자공학 IC-PBL · 주제 3 · 1차 발표
- 하단: 6조 · 2026년 11월

**기호**: 수식 기호는 없다.

**해설**

- 1차 발표의 일은 세 가지다. 무엇을 제어할지 정의하고, 단순한 모델로는 왜 안 되는지 보이고, 그 답을 줄 계산 모델을 세운다.
- 이 범위 때문에 12·13장 각주에 "값은 아직 미산출", "독립 제어 입증 아님"이 반복된다.
- 발표 노트는 20초 인사와 주제 소개다. "이중 코일 유도 결합 플라즈마에서 중앙과 가장자리 전자 밀도를 따로 조절한다"는 한 문장이 발표 전체의 대상을 고정한다.

## 슬라이드 2 · 문제 정의와 제어 목표

제어할 출력은 평균 밀도 n̄\_w와 밀도비 ρ 두 개이고, 목표는 "n̄\_w는 그대로 두고 ρ만 바꾼다"이다.

**화면 구성**

- 위 문단: 문제 정의(하나의 챔버에서 중앙부와 가장자리의 밀도를 독립적으로 조절하는 소스 설계)와 제어 목표(ρ를 전체 밀도 수준과 따로 조정).
- 왼쪽 반단면 개략도: 왼쪽 세로선이 대칭축 r = 0, 오른쪽이 측벽이다. 맨 위 원 6개는 유전체 창 위 코일 도선의 단면이다(파랑 3개 안쪽 코일, 주황 3개 바깥쪽 코일).
- 개략도 아래쪽: 유전체 창, 플라즈마, 웨이퍼 순서다. 웨이퍼 위 관측 높이 z = z\_w에 중앙 영역(0\~r\_c, 파랑 막대)과 가장자리 고리(r\_1\~r\_2, 주황 막대)가 표시돼 있다.
- 오른쪽: ρ 정의 상자, 두 카드(평균 밀도 유지 Δn̄\_w = 0 / 밀도비 조절 Δρ ≠ 0), 주석 "n\_c, n\_edge, n̄\_w: 각 영역의 면적 평균 밀도".
- 결론 줄: 목표는 평균 밀도 n̄\_w를 유지하면서 밀도비 ρ를 바꾸는 것이다.

**식과 기호**

$$
\rho \equiv \frac{n_c}{n_{\mathrm{edge}}}, \qquad \langle n \rangle_S = \frac{1}{A_S}\int_S n(r, z_w)\, 2\pi r\, dr
$$

두 번째 식은 화면 주석의 "면적 평균 밀도"를 식으로 쓴 것이다. 영역 S만 바꿔 넣으면 n\_c, n\_edge, n̄\_w가 모두 이 한 식으로 나온다.

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| ρ (로) | 밀도비. 중앙 평균 밀도 ÷ 가장자리 평균 밀도 | 무차원 |
| ≡ | "\~로 정의한다" |  |
| n\_c | 관측 높이 z\_w에서 중앙 영역(0 ≤ r ≤ r\_c)의 면적 평균 전자 밀도 | m⁻³ |
| n\_edge | 같은 높이에서 가장자리 고리(r\_1 ≤ r ≤ r\_2)의 면적 평균 밀도 | m⁻³ |
| n̄\_w | 관측면 전체(0 ≤ r ≤ R\_w)의 면적 평균 밀도. 발표에서 말하는 "평균 밀도" | m⁻³ |
| r | 대칭축에서 잰 반경 좌표. 그림의 0은 축 위치 | m |
| z, z\_w | 높이 좌표, 그리고 웨이퍼 바로 위에 정한 관측 높이 | m |
| r\_c | 중앙 영역의 바깥 경계 반경 | m |
| r\_1, r\_2 | 가장자리 고리의 안쪽·바깥쪽 경계 반경 | m |
| R\_w | 관측면 전체의 평가 반경(r\_2 이상). 2장 화면에는 없고 12장에 나온다 | m |
| A\_S | 영역 S의 넓이 | m² |
| Δ (델타) | 기준 운전점에서의 변화량. Δn̄\_w = 0은 평균 유지, Δρ ≠ 0은 비가 변한다는 뜻 |  |

**해설**

- 출력이 두 개라는 점이 핵심이다. n̄\_w는 "얼마나 많이"(공정 속도의 크기), ρ는 "어떤 모양으로"(웨이퍼 위 균일도)를 나타낸다.
- 둘을 함께 올리고 내리기는 쉽다. 하나를 고정하고 다른 하나만 움직이려면 서로 독립인 조절 수단이 최소 두 개 필요하다. 이 "출력 2개 대 독립 입력 몇 개"라는 셈이 3·4·13장을 꾰는 축이다.
- 면적 평균을 쓰는 이유: 축대칭이라 면적 요소가 dA = 2πr dr이다. 같은 반경 폭이라도 바깥 고리가 더 넓으므로, 반경 방향으로 단순 평균하면 중앙의 비중이 과대평가된다.
- "ρ는 밀도의 공간 분포에서 정해지는 값"이라는 문구는 5장 문제 1(0D는 ρ를 정의할 수 없음)의 복선이다.
- 압력과 가스는 공정 조건으로 고정하고, 코일 구동만 조절 수단으로 본다. 13장의 "압력 p 고정"과 같은 전제다.

**다음 장으로**: 가장 단순한 0D 모델로 단일 코일부터 따져 본다.

## 슬라이드 3 · 0D에서 본 단일 코일: 입력 하나, 출력 하나

단일 코일의 조절 수단은 전력 하나뿐이라, n̄\_w를 맞추는 순간 ρ를 정할 입력이 남지 않는다.

**화면 구성**

- 왼쪽 그림: 챔버 전체를 상자 하나(T\_e, n\_0)로 본다. 왼쪽에서 P\_abs가 들어오고 오른쪽으로 벽 손실이 나간다. "전자온도 하나, 밀도 하나. 위치(r, z)가 없다."
- 오른쪽 위: 입자 균형 식과 "T\_e는 압력과 용기 크기가 정한다. 전력과 무관하다."
- 오른쪽 아래: 전력 균형 식과 "n\_0는 흡수 전력에 비례한다."
- 아래 흐름: 입력 P → 흡수 전력 P\_abs → 단일 코일 0D 균형 → 출력 n\_0. "n̄\_w를 정하면 P가 정해진다. ρ를 따로 정할 입력이 남지 않는다."
- 결론 줄: 단일 코일로는 평균 밀도를 유지한 채 밀도비를 바꿀 수 없다.

**식 1. 입자 균형** (교재 §2.4 식 (2.70), p.136)

$$
\frac{K_{iz}(T_e)}{u_B(T_e)} = \frac{1}{n_g\, d_{\mathrm{eff}}}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| T\_e | 전자온도. 0D에서는 챔버 전체에 값 하나 | V (eV) |
| K\_iz(T\_e) | 이온화 속도 계수. 전자와 중성 입자가 만나 이온화가 일어나는 빈도로, T\_e가 오르면 지수적으로 커진다 | m³/s |
| u\_B(T\_e) | 봄 속도 √(eT\_e/M). 이온이 쉴스로 들어가는 속도이자 벽 손실 속도 | m/s |
| M | 이온 질량. u\_B 안에 들어 있고 화면에는 없다 | kg |
| n\_g | 중성 기체 밀도 = p/(k\_B T\_g). 압력에 비례 | m⁻³ |
| d\_eff | 유효 플라즈마 크기 = V/A\_eff = RL / \[2(R·h\_L + L·h\_R)\]. 부피를 유효 손실 면적으로 나눈 길이 | m |

식을 n\_gK\_iz = u\_B/d\_eff로 옮기면 뜻이 보인다. 좌변은 전자 하나가 1초에 만드는 이온 수, 우변은 1초에 벽으로 잃는 비율이다. 양변에 밀도나 전력이 없으므로 전자 수가 늘어도 균형을 맞추는 T\_e는 하나로 정해진다.

압력이 높으면(n\_g↑) 충돌이 많아 낮은 T\_e로도 충분하다. 용기가 크면(d\_eff↑) 손실이 느려 T\_e가 역시 낮아진다.

**식 2. 전력 균형** (교재 식 (2.73), p.138. 같은 형태가 식 (2.68), p.135)

$$
n_0 = \frac{P_{\mathrm{abs}}}{e\, u_B\, \varepsilon_T\, A_{\mathrm{eff}}}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| n\_0 | 0D 밀도. 교재에서는 플라즈마 중심(벌크) 밀도이고, 벽 쪽 쉴스 경계 밀도는 h\_L·n\_0, h\_R·n\_0 | m⁻³ |
| P\_abs | 플라즈마가 실제로 흡수한 전력 | W |
| e | 기본 전하 1.6×10⁻¹⁹ | C |
| ε\_T | 전자–이온 쌍 하나가 벽으로 빠져나갈 때 잃는 총 에너지 = ε\_c + ε\_e + ε\_i (식 (2.65)) | V |
| ε\_c | 이온 하나를 만들 때 이온화·여기·탄성 충돌로 잃는 에너지 | V |
| ε\_e | 벽으로 나가는 전자가 들고 가는 운동에너지(≈ 2T\_e) | V |
| ε\_i | 이온이 쉴스를 지나며 얻어 벽으로 들고 가는 에너지 | V |
| A\_eff | 유효 손실 면적 = 2πR²h\_L + 2πRL·h\_R (식 (2.71)–(2.72)) | m² |
| h\_L, h\_R | 축 방향·반경 방향 벽 쪽 밀도 ÷ 중심 밀도. 압력(이온 평균자유행로)과 용기 크기로만 정해진다 | 무차원 |
| R, L | 챔버 반경과 높이 | m |

1초에 벽으로 빠지는 쌍의 수는 n\_0·u\_B·A\_eff이고, 쌍 하나가 eε\_T의 에너지를 가져간다. "흡수 전력 = 손실 전력"에서 n\_0가 나온다.

T\_e가 이미 입자 균형으로 고정돼 u\_B와 ε\_T가 상수이므로, n\_0는 P\_abs에 비례한다.

**흐름 그림의 기호**

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| P | 발생기가 공급하는 전력(입력). P\_abs는 여기서 정합기·안테나 손실을 뺀 값(교재 p.135) | W |
| r, z | 위치 좌표. "0D에는 없다"는 뜻으로 등장 | m |
| n̄\_w, ρ | 2장과 같다 |  |

**해설**

- 결론은 자유도 셈이다. 목표는 n̄\_w와 ρ 두 개인데 조절 수단은 P 하나다. n̄\_w를 맞추는 순간 P가 다 쓰이고, ρ는 그 전력에서 저절로 나오는 값이 된다.
- 이 문제는 0D만의 문제가 아니다. 2D로 계산해도 단일 코일의 입력 개수는 하나다.
- 단일 코일에서 P와 P\_abs는 일대일로 대응하므로 입력은 사실상 하나다.
- 질문 대비 "압력을 바꾸면 되지 않나?": 압력은 공정 화학과 이온 에너지까지 함께 바꾸므로 조절 수단이 아니라 공정 조건으로 고정한다.

**다음 장으로**: 코일을 안쪽과 바깥쪽으로 나눠 입력을 늘린다.

## 슬라이드 4 · 0D에서 본 이중 코일: 입력 셋, 흡수 전력 하나

코일을 둘로 나누면 입력이 k, φ, P\_tot 셋이 되지만, 0D 균형식에는 이 셋이 흡수 전력 P\_abs라는 숫자 하나로만 들어간다.

**화면 구성**

- 왼쪽 위 페이저 그림: 기준 방향(가로)의 I\_in(파랑)과, 그로부터 φ만큼 돌아간 I\_out(주황). 아래에 I\_out = k e^{jφ} I\_in.
- 오른쪽 표: k(전류 크기비, 바깥쪽 코일 항과 간섭항의 크기를 바꾼다), φ(전류 위상차, 간섭항의 크기와 부호를 바꾼다), P\_tot(총 공급 전력, 전류 크기 I\_0를 정한다).
- 가운데: "세 입력이 흡수 전력 하나로 합쳐진다"와 P\_abs 식. 밑줄 라벨은 "크기: P\_tot이 정한다 / 안쪽 코일 / 바깥쪽 코일 / 두 코일의 간섭".
- 아래 흐름: 입력 k, φ, P\_tot → 흡수 전력 P\_abs → 이중 코일 0D 균형 → 출력 n\_0. "0D 식에서 세 입력이 들어갈 자리는 P\_abs뿐이다. 같은 P\_abs면 n\_0도 같고, T\_e는 달라지지 않는다."
- 결론 줄: 입력을 셋으로 늘려도 0D의 출력은 밀도 n\_0 하나다.

**식 1. 두 전류의 관계**

$$
I_{\mathrm{out}} = k\, e^{j\phi}\, I_{\mathrm{in}}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| I\_in | 안쪽 코일 전류의 페이저(위상 기준) | A |
| I\_out | 바깥쪽 코일 전류의 페이저 | A |
| k | 전류 크기비 = I\_out의 크기 ÷ I\_in의 크기 | 무차원 |
| φ (파이) | 전류 위상차 = I\_out의 위상 − I\_in의 위상 | rad |
| j | √−1 |  |
| e^{jφ} | 크기 1, 각도 φ인 회전 인자. 크기는 그대로 두고 위상만 φ만큼 돌린다 |  |

페이저 그림에서 두 화살표의 길이 비가 k, 두 화살표 사이 각이 φ다.

**식 2. 흡수 전력** (팀 유도. 6장의 p\_e를 부피 적분한 형태)

$$
P_{\mathrm{abs}} = \tfrac{1}{2} I_0^2 \left[ R'_{\mathrm{in}} + k^2 R'_{\mathrm{out}} + 2k R'_x \cos(\phi + \psi_0) \right]
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| P\_tot | 두 코일에 공급한 총 전력 | W |
| I\_0 | 공통 전류 진폭 = 안쪽 코일 전류의 크기(피크). 바깥쪽 코일 전류의 크기는 k·I\_0 | A |
| ½ | 피크 페이저를 주기 평균할 때 붙는 인자 |  |
| R'\_in | 안쪽 코일만 1 A로 구동할 때 플라즈마 흡수에 해당하는 등가 저항 = ∫Re(σ\_p)·(Ẽ\_in의 크기)² dV | Ω |
| R'\_out | 바깥쪽 코일만 1 A로 구동할 때의 등가 저항 = ∫Re(σ\_p)·(Ẽ\_out의 크기)² dV | Ω |
| R'\_x | 두 코일의 상호(교차) 저항 크기 = ∫Re(σ\_p)·Ẽ\_in\*·Ẽ\_out dV의 크기 | Ω |
| ψ\_0 (프사이 영) | 위 교차 적분의 위상. 위치마다 다른 두 장의 위상차 ψ(r, z)를 가열 가중으로 평균한 값 | rad |
| cos(φ + ψ\_0) | 간섭항의 부호와 크기를 정하는 인자, −1\~+1 |  |
| P\_abs, n\_0, T\_e | 3장과 같다 |  |

프라임(′)은 교재 변압기 모델의 R'\_p(§2.3.4, p.125)처럼, 플라즈마 전류 루프가 코일 쪽으로 환산돼 보이는 저항이라는 표시다. 코일 전류의 제곱을 곱하면 플라즈마로 들어간 전력이 된다.

바깥쪽 코일 단독 항이 k²인 이유는 전력이 전류의 제곱에 비례하고 바깥쪽 전류가 k·I\_0이기 때문이다. 간섭항은 두 전류의 곱이라 k에 비례한다.

cos(φ + ψ\_0)가 +1에 가까우면 두 장이 같은 방향으로 더해져 흡수가 늘고, −1에 가까우면 상쇄돼 줄어든다. 같은 전류에서도 φ만으로 흡수 전력을 키우거나 줄일 수 있다.

**해설**

- 0D 균형식에는 P\_abs가 들어갈 자리 하나뿐이다. 입자 균형에는 k와 φ가 없으므로 T\_e는 그대로이고, 전력 균형은 P\_abs라는 숫자만 본다.
- 따라서 P\_abs가 같은 (k, φ, P\_tot) 조합은 0D에서 모두 같은 결과를 준다. 입력 공간에서 이런 조합들이 하나의 면을 이루고, 0D는 그 면 위의 점들을 구별하지 못한다.
- 질문 대비 "R′은 상수인가?": 아니다. R′은 플라즈마의 R\_p, L\_p를 통해 밀도에 따라 변한다. 그래서 0D 해는 교재 그림 2.44(p.134)처럼 P\_abs(n) 곡선과 P\_loss(n) 직선의 교점이다. 그래도 k와 φ가 들어가는 통로가 P\_abs 하나라는 결론은 그대로다.
- 질문 대비 "교재의 k와 같은가?": 다르다. 교재 p.125의 k는 결합 계수(M = k√(L\_gL\_a))이고, 이 덱의 k는 전류 크기비다.

**다음 장으로**: 입력을 늘려도 출력이 하나뿐이라는 점에서 0D의 한계가 드러난다.

## 슬라이드 5 · 0D의 한계: 세 가지 문제

0D로는 ρ를 계산할 수도, k와 φ의 효과를 구분할 수도 없으며, 이 세 문제가 2D 모델에 필요한 세 재료(n, p\_e, T\_e·G)를 정한다.

**화면 구성**: 왼쪽에 "0D의 문제" 카드 셋, 오른쪽에 "2D 모델에 필요한 것" 카드 셋이 화살표로 짝지어져 있다. 결론 줄은 "0D로는 ρ를 계산할 수도, k와 φ의 효과를 구분할 수도 없다"이다.

| 번호 | 0D의 문제 | 화면 설명 | 2D 모델에 필요한 것 |
| --- | --- | --- | --- |
| 1 | ρ를 정의할 수 없다 | 결과는 공간 평균 T\_e, n\_0뿐이다 | n(r, z): 중앙과 가장자리를 나누는 밀도 분포 |
| 2 | k와 φ의 효과를 구분할 수 없다 | 세 입력이 P\_abs 하나로만 들어간다 | p\_e(r, z): 위치마다 다른 가열 분포 |
| 3 | T\_e가 균일하면 분포의 모양이 고정된다 | 모양은 용기 크기 R, L이 정한다. ρ는 k, φ와 무관하다 | T\_e(r, z), G(r, z): 위치마다 다른 전자온도와 이온화 |

**식. 문제 3의 확산 방정식과 기본 모드** (교재 §1.10 식 (1.76), p.62 → 해 식 (1.79)·(1.83), p.64)

$$
-D_a \nabla^2 n = \nu_{iz}\, n \;\Longrightarrow\; n \propto J_0\!\left(\frac{\chi_{01}\, r}{R}\right) \cos\frac{\pi z}{L}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| n(r, z) | 위치별 전자 밀도 분포 | m⁻³ |
| p\_e(r, z) | 위치별 흡수 옴전력 밀도(가열 분포) | W/m³ |
| T\_e(r, z) | 위치별 전자온도 | V |
| G(r, z) | 위치별 이온화 생성률. 단위 부피에서 1초에 생기는 이온 수 | m⁻³s⁻¹ |
| D\_a | 양극성 확산 계수 ≈ μ\_iT\_e. 전자와 이온이 함께 퍼지는 빠르기 | m²/s |
| ∇² | 라플라시안. 그 점의 값이 주변 평균보다 얼마나 높은지(곡률)를 나타낸다 | m⁻² |
| ν\_iz | 이온화 주파수 = n\_gK\_iz(T\_e). 전자 하나가 1초에 일으키는 이온화 횟수 | s⁻¹ |
| ⟹ | 따라서 |  |
| ∝ | 비례. 진폭을 빼고 모양만 같다는 뜻 |  |
| J\_0 | 0차 제1종 베셀 함수. 원통의 반경 방향 기본 모양으로, 축에서 최대이고 바깥으로 갈수록 줄어든다 |  |
| χ\_01 (카이 영일) | J\_0의 첫 번째 영점 ≈ 2.405. r = R에서 밀도가 0이 되게 한다 |  |
| R, L | 챔버 반경과 높이 | m |
| z (이 식에서만) | 챔버 높이의 가운데에서 잰 좌표(−L/2\~L/2). 다른 장과 원점이 다르다 | m |
| cos(πz/L) | 축 방향 기본 모양. 가운데서 최대이고 위·아래 벽에서 0 |  |
| ρ, T\_e, n\_0, k, φ, P\_abs | 앞 장과 같다 |  |

좌변 −D\_a∇²n은 한 점에서 확산으로 빠져나가는 양, 우변 ν\_iz·n은 그 점에서 새로 생기는 양이다. 정상상태라 둘이 같다. T\_e가 균일하면 ν\_iz가 어디서나 같은 상수가 된다(교재 p.63).

**해설: 문제 1 (ρ 정의 불가)**

- 0D는 처음부터 위치를 지운 모델이다. 교재 p.137도 이 모델이 공간 평균값을 준다고 밝힌다.
- ρ는 두 위치의 값을 나눈 것이므로 0D 출력으로는 정의되지 않는다. 계산이 부정확한 것이 아니라, 질문을 표현할 변수가 없다.
- 질문 대비 "교재 n\_0는 중심 밀도이고 벽 쪽은 h·n\_0이니 비를 정의할 수 있지 않나?": h\_L, h\_R은 압력과 용기 크기로만 정해진다. 0D가 가진 유일한 모양 정보도 코일과 무관하게 고정돼 있어 결론은 문제 3과 같다.

**해설: 문제 2 (k와 φ 구분 불가)**

- 4장 결론을 한계로 다시 쓴 것이다. k를 바꾼 효과와 φ를 바꾼 효과가 모두 "P\_abs가 조금 변했다"로만 보인다.
- P\_tot으로 같은 만큼 보정하면 둘을 구별할 방법이 없다.
- k와 φ가 고유한 흔적을 남기는 곳은 "어디를 더 가열하느냐"다. 그래서 위치별 가열 분포 p\_e(r, z)가 필요하다.

**해설: 문제 3 (균일 T\_e면 모양 고정)**

- 0D의 가정(균일 T\_e)을 그대로 둔 채 공간만 넓히면 어떻게 되는지 보여 준다.
- T\_e가 균일하면 생성률 ν\_iz·n이 밀도 자체에 비례한다. "어디서 더 만들어지느냐"가 밀도 모양을 그대로 따라가므로, 해는 용기 경계가 정하는 가장 낮은 확산 모드 하나뿐이다.
- ν\_iz는 이 모드를 성립시키는 고윿값이다. 결국 T\_e는 기하가 정하고(3장 입자 균형과 같은 내용) 진폭은 전력이 정한다. 모양에는 코일 정보가 들어갈 자리가 없다.
- 그래서 "가열이 많은 곳에서 T\_e가 높고, 그곳에서 이온화가 더 일어나는" 위치 의존성이 필요하다. K\_iz는 T\_e에 지수적으로 민감해, T\_e가 조금만 달라도 생성 분포가 크게 달라질 수 있다.
- 주의: 저압에서는 전자 열전도가 커서 국소 가열에도 T\_e가 평평해지려 한다. 문제 3에서 실제로 벗어날 수 있는지 자체가 2D 계산으로 확인할 대상이다(7장 각주와 연결).

**다음 장으로**: 오른쪽 카드를 n → p\_e → T\_e, G 순으로 읽으면 그대로 2D 계산 사슬의 재료 목록이 된다.

## 슬라이드 6 · 2D 모델: 0D의 세 문제에 답한다

2D 모델에서 k와 φ는 흡수 전력의 크기가 아니라 가열 분포의 모양을 바꾸며, 그 변화가 ρ까지 가는지를 판정할 수 있다.

**화면 구성**

- 계산 사슬: 코일 전류(I\_0, k, φ) → 유도 전기장 E\_θ(r, z) → 흡수 옴전력 p\_e(r, z) → 전자온도 T\_e(r, z) → 이온화 G(r, z) → 밀도 n(r, z) → ρ.
- 사슬 아래 밑줄: p\_e = 문제 2의 답, T\_e·G = 문제 3의 답, n → ρ = 문제 1의 답.
- 소제목 "2D에서는 k와 φ가 가열 분포의 모양을 바꾼다"와 p\_e 식. 밑줄 라벨은 "안쪽 코일 / 바깥쪽 코일 / 간섭: 위치마다 다르다".
- 아래 페이저 그림과 설명: "한 위치에서 두 코일 장의 합. 사이 각 φ + ψ(r, z)가 위치마다 달라, 보강되는 곳과 상쇄되는 곳이 생긴다."
- 결론 줄: 2D 모델이라야 k와 φ가 밀도비 ρ를 바꾸는지 판정할 수 있다.

**식 1. 한 점에서 두 코일 장의 합** (페이저 그림이 나타내는 식, 팀 유도)

$$
E_\theta(r,z) = I_0 \left[ \tilde{E}_{\mathrm{in}}(r,z) + k\, e^{j\phi}\, \tilde{E}_{\mathrm{out}}(r,z) \right]
$$

**식 2. 흡수 옴전력 밀도** (교재 식 (2.31) p\_e = ½Re(J·E\*), 식 (2.25) J = σ\_pE에 식 1을 대입한 팀 유도)

$$
p_e = \tfrac{1}{2}\,\mathrm{Re}(\sigma_p)\, I_0^2 \left[ |\tilde{E}_{\mathrm{in}}|^2 + k^2 |\tilde{E}_{\mathrm{out}}|^2 + 2k\, |\tilde{E}_{\mathrm{in}}|\, |\tilde{E}_{\mathrm{out}}| \cos(\phi + \psi) \right]
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| θ (세타) | 방위각 방향. 코일을 따라 도는 방향 |  |
| E\_θ(r, z) | 방위각 방향 유도 전기장의 복소 진폭 | V/m |
| p\_e(r, z) | 흡수 옴전력 밀도. 7–9장의 p\_abs와 같은 양 | W/m³ |
| σ\_p | 플라즈마 복소 전도도(8장에서 자세히) | S/m |
| Re(σ\_p) | 그 실수부. 에너지 흡수에 기여하는 부분 | S/m |
| Ẽ\_in, Ẽ\_out | 각 코일에 1 A를 흘렸을 때 생기는 E\_θ 분포(복소). 코일별 "장의 모양" | V/(m·A) |
| Ẽ\_in·Ẽ\_out 크기의 제곱 | 코일 하나만 켰을 때의 가열 모양 |  |
| ψ(r, z) (프사이) | 그 위치에서 Ẽ\_out과 Ẽ\_in의 위상차 | rad |
| φ + ψ | 한 점에서 두 장 사이의 실제 각. 전류로 준 φ에 플라즈마가 만든 ψ가 더해진 것 | rad |
| 그림의 I\_0Ẽ\_in (파랑) | 안쪽 코일이 그 점에 만든 장 | V/m |
| 그림의 k·e^{jφ}·I\_0Ẽ\_out (주황) | 바깥쪽 코일이 그 점에 만든 장 | V/m |
| 그림의 E\_θ (남색) | 두 화살표의 합. 실제 전기장 | V/m |
| I\_0, k, φ | 4장과 같다 |  |
| T\_e, G, n, ρ | 5장과 같다(위치별 값) |  |

식 2의 괄호는 E\_θ 크기의 제곱을 풀어 쓴 것이다. 첫째 항은 안쪽 코일 혼자의 가열, 둘째는 바깥쪽 코일 혼자의 가열, 셋째는 두 장이 겹쳐서 생기는 간섭이다.

앞의 ½Re(σ\_p)는 "그 자리의 플라즈마가 장의 에너지를 얼마나 잘 받아들이는가"를 뜻한다. n\_e와 T\_e에 따라 위치마다 다르다.

**해설**

- ψ가 생기는 이유: 진공에서는 두 코일의 장이 같은 위상이다. 플라즈마 안에서는 표피 효과(교재 식 (2.53), p.122)로 장이 감쇠하며 위상이 밀린다. 두 코일은 위치가 달라 한 점에 이르는 경로가 다르므로 위상 지연도 위치마다 다르다.
- 가열 모양이 바뀌는 경로 1, k: 세 항의 공간 모양이 서로 다르다. 안쪽 코일 아래는 첫째 항이, 바깥쪽 코일 아래는 둘째 항이 크다. k가 두 모양의 가중치를 바꾸므로 가열 중심이 안팎으로 움직인다.
- 가열 모양이 바뀌는 경로 2, φ: ψ가 위치마다 다르므로, φ를 바꾸면 cos(φ + ψ)가 양수인 보강 영역과 음수인 상쇄 영역의 위치가 옮겨 간다.
- 4장과의 관계: p\_e를 부피 적분하면 4장의 P\_abs가 된다. 적분하는 순간 ψ(r, z)는 ψ\_0 하나로, 장 세기의 공간 모양은 R′ 값 하나로 줄어든다. 0D에서 크기로만 보이던 k와 φ가 2D에서 모양을 바꾸는 입력이 되는 이유다.
- 결론이 "바꾼다"가 아니라 "판정할 수 있다"인 이유: 가열 모양과 밀도 모양 사이에 열전도(T\_e를 퍼뜨림)와 확산(밀도를 퍼뜨림)이 끼어 있다. 가열 변화가 ρ까지 전달되는지는 계산해 봐야 안다.

**다음 장으로**: 이 사슬을 실제 계산 순서로 펼친다.

## 슬라이드 7 · 2D 모델링 과정

한 운전점을 고정하고 전자기장 → 전자 에너지 → 입자 수송을 푼 뒤, 새 n\_e·T\_e로 전도도부터 다시 계산하는 고리를 수렴할 때까지 돈다.

**화면 구성**

- 부제: 기본 가정과 전체 계산 흐름 — 운전 조건에서 n\_e(r, z), T\_e(r, z)까지.
- 계산 지도: 위 줄은 왼쪽에서 오른쪽, 아래 줄은 오른쪽에서 왼쪽으로 읽는다. 순서는 아래 목록과 같다.
- 주황 점선: 5.10–11에서 5.2로 돌아가는 고리. "미수렴: 새 n\_e, T\_e → σ\_p 재계산".
- 범례 색: 전자기 결합(5.2–5.5), 에너지·이온화(5.6–5.7), 확산·벽 손실(5.8).
- 오른쪽 주석: "n\_e, T\_e는 처음부터 미지수 · 한 운전점 (p, P\_tot, k, φ) 고정".
- 아래: 기본 가정 표, 결론 줄 "한 운전점에서 전자기장 → 에너지 → 입자 수송을 풀고, 수렴할 때까지 반복."
- 각주: "가정의 정확성은 아직 검증 전 — 특히 약 10 mTorr의 국소 Maxwellian·유체 수송 근사는 2차 연구 검증 항목".

**계산 순서**

1. 설정, 운전 조건: p, P\_tot, k, φ
2. 5.1 0D 초기값: T\_e0, n\_\*
3. 5.2 복소 전도도: σ\_p(r, z)
4. 5.3 RF 전자기장: E\_θ(r, z)
5. 5.4–5.5 흡수 전력: I\_0, p\_abs(r, z)
6. 5.6 전자 에너지: T\_e(r, z)
7. 5.7 이온화 생성률: G\_iz(r, z)
8. 5.8 입자 수송: n\_e(r, z)
9. 5.10–11 자기일관 수렴: 격자 연립 + 반복. 미수렴이면 3번으로 돌아간다
10. 5.12 최종 밀도 분포: n\_e\*, T\_e\* → n̄\_w, ρ

**기호**

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| p | 기체 압력(소문자). 운전 조건으로 고정 | mTorr (1 mTorr ≈ 0.133 Pa) |
| T\_e0 | 0D 입자 균형으로 구한 전자온도. 초기값 | V |
| n\_\* | 0D 전력 균형으로 구한 밀도 규모. 초기값(아래첨자 \*) | m⁻³ |
| σ\_p(r, z) | 위치별 복소 전도도 | S/m |
| I\_0 | 공통 전류 진폭. 반복마다 포트 전력 조건으로 다시 정해진다 | A |
| p\_abs(r, z) | 흡수 전력 밀도. 6장 p\_e와 같은 양 | W/m³ |
| G\_iz(r, z) | 이온화 생성률. 5·6장 G와 같은 양 | m⁻³s⁻¹ |
| n\_e(r, z) | 전자 밀도. 5·6장 n과 같은 양이고, 준중성이라 이온 밀도와도 같다 | m⁻³ |
| n\_e\*, T\_e\* | 수렴한 정상상태 해(위첨자 \*) |  |
| 5.1\~5.12 | 팀 상세 보고서의 절 번호. 5.9는 화면에 없다 |  |
| P\_tot, k, φ, E\_θ, T\_e(r, z), n̄\_w, ρ | 앞 장과 같다 |  |

**기본 가정 표 풀이**

| 구분 | 가정 | 뜻과 이유 |
| --- | --- | --- |
| 기하·시간 | 축대칭 (r, z) | 코일과 챔버가 원형이라 θ 방향 변화가 없다고 보고 3D를 2D로 줄인다 |
| 기하·시간 | 정상상태 | RF 한 주기 평균으로 보아 시간 변화가 없는 상태. 펄스 운전은 범위 밖 |
| 기하·시간 | 단일 RF 주파수 | 두 코일 주파수가 같아야 φ가 시간에 대해 고정된다. 다르면 위상차가 계속 돌아 간섭항이 시간 평균으로 사라진다 |
| 입자종 | Ar, 전자 및 Ar⁺ 중심 | 음이온, 준안정 상태를 거치는 단계 이온화, 여러 이온종은 뺀다 |
| 입자종 | 준중성 벌크 | n\_i ≈ n\_e. 쉴스는 직접 풀지 않고 경계 조건(Bohm 유출)으로 처리한다 |
| 전자 에너지 | 2D 유체 열전도·수송 | T\_e를 국소 에너지 방정식으로 구한다. 전자 에너지 분포를 직접 푸는 운동론 모델이 아니다 |
| 중성기체 | 균일 n\_g 및 기체 온도 | 중성 기체의 고갈과 가열을 무시한다 |

각주의 "국소 Maxwellian"은 각 위치의 전자 에너지 분포가 그 위치 T\_e의 맥스웰 분포라는 가정이다. 이 가정이 있어야 K\_iz와 ν\_m을 T\_e 하나의 함수로 쓸 수 있다.

**해설**

- 6장 사슬을 실제 계산 순서로 펼친 지도다. 6장과 다른 점은 둘이다. 사슬이 한 방향으로 끝나지 않고 고리가 되며, 0D가 다시 나오지만 답이 아니라 출발점 역할을 한다.
- 고리가 생기는 이유: 밀도와 온도가 바뀌면 전도도가 바뀌고, 전도도가 바뀌면 장과 가열 분포가 바뀐다.
- "처음부터 미지수"의 뜻: n\_e와 T\_e를 다른 곳에서 빌려 오지 않고 이 계산이 스스로 정한다. 계산 한 번은 운전점 하나만 다루며, 여러 운전점 비교는 13장의 일이다.
- 색 구분은 세 물리 과정이다. 코일과 플라즈마의 전자기 결합, 전자가 에너지를 받아 이온화하는 과정, 입자가 퍼져 벽으로 잃어지는 과정이다.
- 각주의 뜻: 저압에서는 전자가 에너지를 잃기 전에 멀리 이동해 "그 위치의 T\_e"라는 개념이 약해질 수 있다. 5장 문제 3과 직접 이어지는 위험 요소를 밝힌 것이다.

**다음 장으로**: 지도의 첫 구간(초기값 → 전도도 → 전기장)을 식으로 본다.

## 슬라이드 8 · 2D 모델링, 초기값과 RF 전기장

현재 n\_e·T\_e 지도로 전도도 σ\_p를 만들고, 축대칭 유도장 방정식을 풀어 공간별 RF 전기장 E\_θ(r, z)를 얻는다.

**화면 구성**

- 부제: 0D 초기값, 복소 전도도, 축대칭 RF 유도장 → E\_θ(r, z).
- 네 줄의 식: 0D 초기값, 복소 전도도, 2D 유도장, 두 코일 중첩.
- 오른쪽 주석: "입자 균형 → T\_e0, 전력 균형 → n\_\*", "n\_e: 분자에 직접 비례, T\_e: ν\_m(T\_e)로 반영", "미지수 A\_θ(r, z)".
- 아래 글상자 세 줄, 결론 줄 "출력은 공간별 RF 전기장 E\_θ(r, z)이며, 다음 단계 흡수 전력 계산에 쓰인다."
- 맨 아래: 받는 값 운전 조건 (p, P\_tot, k, φ) → 넘기는 값 E\_θ(r, z), A\_in, A\_out.

**식 1. 0D 초기값**

$$
n_e^{(0)}(r,z) = n_*, \qquad T_e^{(0)}(r,z) = T_{e0}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| n\_e^(0), T\_e^(0) | 반복 0회째, 곧 초기 지도. 격자 전체에 같은 값을 넣는다 | m⁻³, V |
| n\_\*, T\_e0 | 0D 전력 균형·입자 균형에서 구한 값(7장) | m⁻³, V |

3장의 0D가 "첫 추정 지도"로 재활용된다. 첫 반복에만 쓰고, 이후에는 매번 새로 구한 값으로 바뀐다.

**식 2. 복소 전도도** (교재 §2.3.1 식 (2.26), p.103)

$$
\sigma_p(r,z) = \frac{n_e(r,z)\, e^2}{m_e \left[ \nu_m\big(T_e(r,z)\big) + j\omega \right]}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| σ\_p(r, z) | 플라즈마 복소 전도도. 전기장에 대해 전자가 얼마나 전류를 흘리는지 | S/m |
| e | 기본 전하 | C |
| m\_e | 전자 질량 9.11×10⁻³¹ | kg |
| ν\_m(T\_e) | 전자–중성 운동량 전달 충돌 주파수 = n\_gK\_m(T\_e). 전자가 1초에 방향을 잃는 충돌 횟수 | s⁻¹ |
| ω | RF 각주파수 = 2πf | rad/s |
| j | √−1 |  |

전자는 RF 장에 흔들리면서 관성(jω)과 충돌 마찰(ν\_m)을 함께 받는다. n\_e는 분자에 직접 들어가고(전자가 많을수록 전류를 많이 나름), T\_e는 ν\_m을 통해 들어간다.

실수부는 에너지를 흡수하는 저항 성분, 허수부는 전자 관성에서 오는 유도성 성분이다. n\_e와 T\_e가 위치마다 다르므로 σ\_p도 공간 지도가 된다.

**식 3. 2D 유도장 방정식**

$$
\left[ \frac{\partial}{\partial r}\frac{1}{r}\frac{\partial (r\,\cdot)}{\partial r} + \frac{\partial^2}{\partial z^2} - j\omega\mu_0\sigma_p \right] A_\theta = -\mu_0 J_{\mathrm{coil},\theta}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| ∂/∂r, ∂/∂z | 반경·높이 방향 편미분 |  |
| (r·) | 괄호 자리에 A\_θ를 넣어 r·A\_θ를 미분하라는 표시 |  |
| 앞의 두 미분 항 | 원통좌표에서 θ 성분의 라플라시안. 장이 공간에서 어떻게 휘고 퍼지는지 | m⁻² |
| μ\_0 | 진공 투자율 4π×10⁻⁷ | H/m |
| A\_θ(r, z) | 방위각 방향 자기 벡터 퍼텐셜의 복소 진폭. 이 단계의 미지수 | Wb/m |
| J\_coil,θ | 코일 도선 안의 θ 방향 전류 밀도. 코일 단면에서만 0이 아니다 | A/m² |
| −jωμ\_0σ\_p | 플라즈마에 유도된 전류 항. 장을 가리는 표피 효과를 만든다 | m⁻² |

맥스웰 방정식(앙페르와 패러데이 법칙)을 축대칭 벡터 퍼텐셜 하나로 쓴 것이다. 우변의 코일 전류가 원천이고, 플라즈마는 코일과 반대 방향의 전류를 유도해 장을 가린다.

밀도가 높을수록 σ\_p의 크기가 커져 장이 빨리 줄어든다(표피 깊이, 교재 식 (2.53), p.122). 교재 식 (2.52)의 솔레노이드 장(E\_θ ∝ ωI\_0r)이 가장 단순한 경우이고, 이 식은 실제 기하와 플라즈마 분포에서의 일반형이다.

**식 4. 두 코일 중첩**

$$
E_\theta = -j\omega A_\theta = -j\omega I_0 \left( A_{\mathrm{in}} + k\, e^{j\phi} A_{\mathrm{out}} \right)
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| A\_in, A\_out | 각 코일에 1 A를 흘렸을 때의 A\_θ, 곧 단위 전류 응답. 6장의 Ẽ와는 Ẽ = −jωA 관계 | Wb/(m·A) |
| −jω | 페이저에서의 시간 미분. 전기장은 퍼텐셜이 시간에 따라 변하는 빠르기 | rad/s |
| I\_0, k, φ | 4장과 같다 |  |

축대칭이라 θ 방향 정전기장이 없으므로 E\_θ는 A\_θ만으로 정해진다.

**글상자 해설**

- "0D 값은 첫 회의 초기 지도로만 사용": 식 1의 뜻이다. 이후 반복마다 새 n\_e, T\_e로 σ\_p를 갱신한다.
- "σ\_p를 고정하면 방정식이 전류에 선형": 이 장의 계산상 핵심이다. 한 반복 안에서는 각 코일에 1 A씩 흘린 응답을 한 번씩만 풀면 되고, 어떤 k, φ든 두 응답의 가중합으로 바로 만든다.
- "창·진공 영역 σ\_p = 0": 장이 퍼지기만 하고 흡수는 없다. "축 r = 0 정규성": 축 위에서 A\_θ = 0이다.
- "공통 전류 진폭 I\_0는 포트 전력 조건(부록)": 두 포트로 들어간 전력의 합이 P\_tot이 되도록 I\_0를 정한다. 플라즈마 부하가 반복마다 바뀌므로 I\_0도 반복마다 다시 정해진다.
- 암묵적 가정: 변위 전류를 무시한 준정적 근사다. 13.56 MHz라면 파장이 20 m 남짓으로 챔버보다 훨씬 커서 타당하다.

**다음 장으로**: 이 E\_θ로 흡수 전력을 계산하고 전자 에너지 방정식에 넣는다.

## 슬라이드 9 · 2D 모델링, 흡수 전력과 전자 에너지 방정식

흡수 전력은 곧바로 이온 생성률로 바꾸지 않고 전자 에너지 방정식의 가열항으로 넣어, 에너지 수송까지 거친 공간별 전자온도 T\_e(r, z)를 구한다.

**화면 구성**

- 부제: 주기 평균 흡수 전력 밀도, 전자 에너지 보존 → T\_e(r, z).
- 위 세 식(흡수 전력, 전도도 실수부, 전자 에너지)과 오른쪽 주석 "피크 페이저 → 주기 평균 1/2", "Re(σ\_p)만 에너지 흡수에 기여", "미지수 T\_e(r, z)".
- 가운데 네 상자: RF 흡수 전력, 전자 에너지 수송, 양극성 장 에너지 교환, 충돌 손실.
- 아래 왼쪽 출력 상자 "공간별 전자온도 T\_e(r, z) → K\_iz(T\_e), ν\_m(T\_e) 평가에 사용", 오른쪽 "단독 풀이 불가: 수송항·충돌항에 n\_e 포함 → 입자 방정식과 연립".
- 결론 줄: 흡수 전력은 생성률로 바로 바꾸지 않고, 에너지 방정식의 가열항으로 쓴다.
- 맨 아래: 받는 값 E\_θ(r, z), 현재 σ\_p, n\_e → 넘기는 값 T\_e(r, z).

**식 1. 흡수 전력 밀도** (교재 식 (2.31), p.105)

$$
p_{\mathrm{abs}}(r,z) = \frac{1}{2}\,\mathrm{Re}\left[\sigma_p(r,z)\right] \left|E_\theta(r,z)\right|^2
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| p\_abs(r, z) | 주기 평균 흡수 전력 밀도. 6장 p\_e와 같은 양 | W/m³ |
| ½ | 피크 페이저에서 cos²의 주기 평균 |  |
| Re\[σ\_p\] | 전도도 실수부. 에너지 흡수에 기여하는 부분 | S/m |
| E\_θ 크기의 제곱 | 장 세기의 제곱(피크 기준) | V²/m² |

허수부는 한 주기 동안 에너지를 주고받기만 해서 평균 흡수가 0이다. 그래서 실수부만 남는다.

**식 2. 전도도 실수부** (식 (2.26)의 실수부. 교재 식 (2.32)와 같은 형태)

$$
\mathrm{Re}(\sigma_p) = \frac{n_e e^2\, \nu_m}{m_e \left( \nu_m^2 + \omega^2 \right)}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| ν\_m² + ω² | 충돌(ν\_m)과 진동(ω)의 경쟁을 나타내는 분모 | s⁻² |
| n\_e, e, m\_e, ν\_m, ω | 8장과 같다 |  |

충돌이 없으면(ν\_m → 0) 전자는 장을 따라 흔들리기만 하고 에너지를 얻지 못한다. 충돌이 진동을 무작위 운동으로 바꿔 줘야 흡수가 일어난다. 밀도가 같다면 ν\_m이 ω와 비슷할 때 흡수가 가장 크다.

**식 3. 전자 에너지 보존과 네 상자의 식**

$$
\nabla \cdot \mathbf{q}_\varepsilon = p_{\mathrm{abs}} + \mathbf{J}_{e,\mathrm{dc}} \cdot \mathbf{E}_a - P_{\mathrm{coll}}
$$

$$
\mathbf{q}_\varepsilon = \tfrac{5}{2}\, e T_e\, \boldsymbol{\Gamma}_e - \kappa_e \nabla T_e, \qquad \mathbf{J}_{e,\mathrm{dc}} = -e\,\boldsymbol{\Gamma}_e, \qquad P_{\mathrm{coll}} \simeq e\, n_e n_g K_{iz}(T_e)\, \varepsilon_c(T_e)
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| ∇· | 발산. 그 점에서 바깥으로 빠져나가는 순유출량 | m⁻¹ |
| q\_ε | 전자 에너지 선속 벡터. 단위 면적을 1초에 지나가는 전자 에너지 | W/m² |
| 5/2 | 전자 하나가 실어 나르는 엔탈피 계수(운동에너지 3/2 + 압력 일 1) |  |
| Γ\_e | 전자 입자 선속. 양극성이므로 10장의 Γ와 같다 | m⁻²s⁻¹ |
| κ\_e | 전자 열전도도. 저압일수록 크다 | W/(m·V) |
| ∇T\_e | 전자온도 기울기 | V/m |
| J\_e,dc | 전자 전류 밀도의 주기 평균 성분 = −eΓ\_e. 전자 전하가 음이라 흐름과 방향이 반대 | A/m² |
| E\_a | 양극성 전기장. 벌크의 정전기장으로 전자를 가두는 방향 | V/m |
| P\_coll | 충돌로 잃는 에너지율 밀도 | W/m³ |
| ε\_c(T\_e) | 이온 하나를 만들 때 이온화·여기·탄성 충돌로 잃는 평균 에너지(교재 식 (2.65)의 ε\_c) | V |
| ≃ | 근사적으로 같다 |  |
| n\_g, K\_iz(T\_e) | 3장과 같다 |  |

식 3은 "한 점에서 빠져나가는 에너지 흐름 = 들어오는 가열 + 장과의 교환 − 충돌 손실"이다. 네 상자는 각 항의 뜻이다.

- RF 흡수 전력 p\_abs: 전자가 공급받는 에너지, 곧 원천이다.
- 전자 에너지 수송 q\_ε: 앞 항은 전자 흐름이 실어 나르는 에너지(대류), 뒷 항은 뜨거운 곳에서 찬 곳으로 가는 열전도다. 흡수 지점의 에너지를 다른 위치로 옮긴다.
- 양극성 장 교환 J\_e,dc·E\_a: 벽으로 빠져나가는 전자는 자신을 가두는 장을 거슬러 올라가므로 보통 이 항에서 에너지를 잃는다. 잃은 에너지는 이온 가속으로 간다.
- 충돌 손실 P\_coll: 이온 하나를 만들 때마다 ε\_c만큼 잃는다. 0D의 ε\_c를 위치별로 쓴 것이다.

**해설**

- 이 식이 5장 문제 3의 승부처다. κ\_e가 크면(저압) T\_e가 평평해져 가열 모양이 지워지고, 작으면 가열 모양이 T\_e 모양으로 남는다.
- 출력 T\_e(r, z)는 K\_iz(T\_e)와 ν\_m(T\_e) 계산에 쓰인다. K\_iz는 다음 장 생성률에, ν\_m은 다음 반복의 전도도에 들어간다.
- 단독 풀이 불가: 수송항(Γ\_e, κ\_e)과 충돌항에 n\_e가 들어 있어 입자 방정식과 연립해야 한다.
- 결론 줄의 뜻: 0D식으로는 "p\_abs ÷ eε\_T = 그 자리 생성률"로 바로 바꾸고 싶어진다. 그러면 "가열이 많은 곳에서 생성도 많다"는 가정을 미리 박아 넣는 셈이다. 이 모델은 사이에 에너지 수송을 넣어, 가열 위치와 이온화 위치가 얼마나 어긋나는지까지 계산한다.

**다음 장으로**: 이 T\_e로 이온화 생성률을 만들고 입자 수송 식과 연립한다.

## 슬라이드 10 · 2D 모델링, 이온화 생성률과 양극성 확산

이온화와 양극성 확산을 입자 보존식 하나로 묶으면 5장 확산 방정식을 T\_e(r, z)까지 허용하도록 넓힌 최종 입자 방정식이 되고, 이것을 에너지 식과 연립해 n\_e와 T\_e를 함께 구한다.

**화면 구성**

- 부제: 이온화 생성률, 양극성 선속, 입자 보존 → n\_e(r, z).
- 위 세 식과 오른쪽 주석: "T\_e → K\_iz, 단 미지수 n\_e가 곱해진 형태", "1항: 밀도 구배 확산, 2항: 온도 구배 효과", "생성 = 선속 발산 (체적 재결합 무시)".
- 가운데 박스: 최종 입자 방정식.
- 아래 왼쪽 상자 "두 PDE의 연립 — 미지수 n\_e(r, z), T\_e(r, z)": 연립식, "위: 전자 에너지 (5.6) · 아래: 입자 수송 (5.8)", "n\_e는 에너지 식의 κ\_e, P\_coll에, T\_e는 입자 식의 K\_iz, ∇T\_e에 들어감". 화살표 오른쪽은 "연립해 T\_e(r, z), n\_e(r, z)".
- 결론 줄: 에너지 식과 입자 식을 함께 풀어야 T\_e(r, z), n\_e(r, z)가 정해진다.
- 각주: 경계는 축 r = 0 대칭, 상·하부·측벽 Bohm 유출 손실(상세 생략).

**식 1. 이온화 생성률**

$$
G_{iz}(r,z) = n_e(r,z)\, n_g\, K_{iz}\big(T_e(r,z)\big)
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| G\_iz(r, z) | 이온화 생성률. 단위 부피에서 1초에 생기는 이온 수 | m⁻³s⁻¹ |
| n\_e, n\_g, K\_iz(T\_e) | 앞 장과 같다 |  |

교재의 반응률식 그대로다. T\_e를 알아도 n\_e가 곱해져 있어 한 번 대입으로 끝나지 않는다. K\_iz는 T\_e에 지수적으로 민감해, 생성이 T\_e가 높은 곳으로 몰린다.

**식 2. 양극성 선속**

$$
\boldsymbol{\Gamma} \simeq -\mu_i \nabla (n_e T_e) = -\mu_i T_e \nabla n_e - \mu_i n_e \nabla T_e
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| Γ | 양극성 입자 선속. 전자와 이온이 같은 속도로 함께 빠져나가는 흐름 | m⁻²s⁻¹ |
| μ\_i | 이온 이동도. 전기장 1 V/m당 이온의 표류 속도 | m²/(V·s) |
| ∇ | 기울기. 가장 가파르게 증가하는 방향과 그 크기 | m⁻¹ |
| n\_eT\_e | 전자 압력을 e로 나눈 값(전자 압력 = e·n\_e·T\_e) | m⁻³·V |
| μ\_iT\_e | 양극성 확산 계수 D\_a와 같은 양(T\_i ≪ T\_e일 때) | m²/s |

전자 압력의 기울기가 플라즈마를 밀어내고, 이온은 양극성 장에 끌려 같은 속도로 나간다. 1항은 교재의 일반적인 밀도 구배 확산(−D\_a∇n)이다.

2항은 온도 구배 효과로, 뜨거운 곳이 플라즈마를 밀어낸다. T\_e가 균일하면 2항은 사라진다.

**식 3. 입자 보존** (교재 식 (1.75)의 정상상태형)

$$
\nabla \cdot \boldsymbol{\Gamma} = G_{iz}
$$

한 점에서 새로 만들어진 만큼 빠져나간다는 뜻이다. 저압에서는 벽 손실이 체적 재결합보다 압도적이라 재결합을 무시한다.

**식 4. 최종 입자 방정식** (화면 박스)

$$
\nabla \cdot \left[ \mu_i \nabla (n_e T_e) \right] + n_e\, n_g\, K_{iz}(T_e) = 0
$$

식 2를 식 3에 넣은 것이다. T\_e를 상수로 두면 μ\_iT\_e∇²n\_e + ν\_iz·n\_e = 0, 곧 5장의 −D\_a∇²n = ν\_iz·n으로 돌아간다.

이 식은 5장 문제 3의 식을 T\_e(r, z)까지 허용하도록 일반화한 것이다. T\_e가 위치마다 다를 때만 생성 분포의 변화와 온도 구배 수송을 통해 밀도 모양이 기본 모드에서 벗어날 수 있다. 문제 3에 대한 답이 수식으로 드러나는 곳이다.

**식 5. 두 PDE의 연립** (화면 왼쪽 아래 상자)

$$
\begin{cases} \nabla \cdot \mathbf{q}_\varepsilon = p_{\mathrm{abs}} + \mathbf{J}_{e,\mathrm{dc}} \cdot \mathbf{E}_a - P_{\mathrm{coll}} \\ \nabla \cdot \left[ \mu_i \nabla (n_e T_e) \right] + n_e n_g K_{iz}(T_e) = 0 \end{cases}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| (5.6), (5.8) | 팀 보고서의 식 번호. 각각 전자 에너지 식과 입자 수송 식 |  |
| r = 0 대칭 | 축에서 반경 방향 기울기가 0 |  |
| Bohm 유출 | 벽에서 Γ·n̂ = n\_e·u\_B. 벽 쪽 밀도에 봄 속도를 곱한 만큼 빠져나간다 | m⁻²s⁻¹ |
| q\_ε, J\_e,dc, E\_a, P\_coll, κ\_e, p\_abs | 9장과 같다 |  |

**해설**

- 두 식은 서로 얽혀 있다. n\_e는 에너지 식의 κ\_e와 P\_coll에, T\_e는 입자 식의 K\_iz와 ∇T\_e에 들어 있어 따로 풀 수 없다.
- 0D와의 대응: 입자 식은 T\_e를 고정하면 n\_e에 대해 선형이라, 밀도의 모양과 T\_e는 정하지만 크기는 정하지 못한다. 크기는 에너지 식에 들어오는 흡수 전력이 정한다.
- 즉 3장의 "입자 균형 → T\_e, 전력 균형 → n\_0"가 2D에서 연립된 형태다.

**다음 장으로**: 이 연립해가 다시 전도도와 전기장을 바꾸므로 전체를 반복한다.

## 슬라이드 11 · 2D 모델링, 정상상태 도출

밀도·온도 → 전도도 → 전기장 → 흡수 전력 → 새 밀도·온도의 고리를, 갱신량과 보존 오차가 모두 작아질 때까지 반복해 정상상태 n\_e\*, T\_e\*를 얻는다.

**화면 구성**

- 부제: 자기일관 반복 → 정상상태 (n\_e\*, T\_e\*).
- 맨 위: 반복 고리 식.
- 순서도: 시작(0D 초기값, m = 0) → 현재 상태 → 전도도 → 전자기장 → 전류·흡수 전력 → 에너지–입자 연립 → 수렴? 아니오면 m ← m+1로 현재 상태에 돌아가고(주황 점선), 예이면 정상상태 n\_e\*(r, z), T\_e\*(r, z).
- 오른쪽 "수렴 판정" 상자: ① 수치 갱신량, ② 물리적 보존 오차, ③ 전자 에너지·전력 수지 점검, "갱신 시 완화(relaxation)로 진동 억제".
- 결론 줄: 밀도·온도가 바뀌면 전도도와 전기장이 바뀌므로, 수렴할 때까지 반복한다.
- 각주: 수치 수렴은 채택한 방정식을 풀었다는 뜻이며, 국소 Maxwellian 등 모델 가정의 검증은 아님.

**식 1. 반복 고리**

$$
\left(n_e^{(m)}, T_e^{(m)}\right) \to \sigma_p^{(m)} \to E_\theta^{(m)} \to p_{\mathrm{abs}}^{(m)} \to \left(n_e^{(m+1)}, T_e^{(m+1)}\right)
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| (m) | m번째 반복의 값 |  |
| m = 0 | 반복 시작. 0D 초기값(8장 식 1) |  |
| m ← m+1 | 반복 번호를 하나 늘린다 |  |
| n\_e^(m), T\_e^(m) | 순서도의 "현재 상태" | m⁻³, V |
| σ\_p^(m) | 현재 상태로 계산한 전도도(8장 식 2) | S/m |
| A\_θ^(m), E\_θ^(m) | 그 전도도로 푼 벡터 퍼텐셜과 전기장(8장 식 3·4) | Wb/m, V/m |
| I\_0^(m), p\_abs^(m) | 포트 전력 조건으로 다시 정한 전류 진폭과 흡수 전력 밀도 | A, W/m³ |
| n\_e^(m+1), T\_e^(m+1) | 에너지–입자 연립(10장 식 5)으로 얻은 다음 추정값 | m⁻³, V |
| n\_e\*, T\_e\* | 수렴한 정상상태 해 | m⁻³, V |

**식 2. 수렴 판정 ①②**

$$
\left\| n_e^{(m+1)} - n_e^{(m)} \right\| \to 0, \qquad \left\| T_e^{(m+1)} - T_e^{(m)} \right\| \to 0
$$

$$
\int_V G_{iz}\, dV \simeq \oint_{\partial V} \boldsymbol{\Gamma} \cdot \hat{\mathbf{n}}\, dA
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| ‖·‖ | 노름. 격자 전체에 걸친 차이의 크기를 숫자 하나로 나타낸 것(최댓값이나 제곱평균) |  |
| → 0 | 허용 오차 이하로 작아진다 |  |
| V, dV | 플라즈마 부피와 부피 요소. 축대칭이면 dV = 2πr dr dz | m³ |
| ∫\_V G\_iz dV | 플라즈마 전체에서 1초에 생기는 이온 수 | s⁻¹ |
| ∂V | 부피를 둘러싼 경계면(벽) |  |
| n̂ | 경계면의 바깥 방향 단위 법선 벡터 |  |
| dA | 면적 요소 | m² |
| ∮\_∂V Γ·n̂ dA | 경계면 전체로 1초에 빠져나가는 입자 수 | s⁻¹ |
| 완화(relaxation) | 새 값을 그대로 쓰지 않고 이전 값 쪽으로 일부만 옮기는 갱신. 갱신 비율은 화면에 없다 |  |

**해설**

- 반복이 필요한 이유: 전기장(8장)을 풀려면 n\_e와 T\_e가 필요하고, n\_e와 T\_e(9·10장)를 풀려면 전기장에서 나온 p\_abs가 필요하다. 서로가 서로를 필요로 하므로 추정 → 계산 → 갱신을 되풀이한다.
- 정상상태는 "이 지도로 장을 계산하고, 그 장으로 다시 지도를 계산했더니 같은 지도가 나오는" 상태다. 교재 그림 2.44에서 흡수 곡선과 손실 직선의 교점을 찾는 일을 공간 전체에서 하는 셈이다.
- 되먹임의 물리: 창 아래 밀도가 오르면 장이 더 빨리 가려져 가열이 얇은 층으로 몰리고, 이것이 다시 T\_e와 밀도 분포를 바꾼다.
- 플라즈마 부하가 바뀌므로 같은 P\_tot을 맞추는 I\_0도 매번 달라진다. 순서도에 "전류·흡수 전력" 단계가 따로 있는 이유다.
- 수렴 판정의 역할: ①은 "숫자가 멈췄는가", ②는 "전체 생성 = 전체 벽 손실"(입자 수지), ③은 "전체 흡수 = 전체 손실"(에너지 수지)이다. ①만 보면 아주 느리게 변하는 틀린 해에서 멈출 수 있다. ②③은 3장의 0D 균형을 부피 전체 합으로 다시 확인하는 것이다.
- 완화가 필요한 이유: 새 값을 그대로 쓰면 "밀도 과대 → 장 차폐 → 가열 감소 → 밀도 과소…"로 출렁일 수 있다. 이전 값과 새 값 사이로 조금씩 옮겨 진동을 막는다.
- 각주의 뜻: 수렴은 "고른 방정식을 제대로 풀었다"는 뜻일 뿐이다. 그 방정식이 실제 플라즈마를 맞게 나타낸다는 증거는 아니다.

**다음 장으로**: 수렴한 지도에서 웨이퍼 관측면의 지표를 뽑는다.

## 슬라이드 12 · 2D 모델링, 최종 계산 결과

수렴한 밀도 지도를 웨이퍼 관측 높이에서 잘라 면적 평균하면 2장의 지표 n̄\_w와 ρ가 나오며, 이 단계에는 새 물리 방정식이 없다.

**화면 구성**

- 부제: 수렴한 2D 지도 → 웨이퍼 관측면 지표 (n̄\_w, ρ) 추출 (새 방정식 없음).
- 왼쪽 위: 점선 사각형 두 개. T\_e\*(r, z) "2D 전자온도 지도", n\_e\*(r, z) "2D 전자 밀도 지도". 밀도 지도에 주황 점선 z = z\_w가 있고, 거기서 아래로 화살표가 나온다.
- 왼쪽 아래: 반경 축 n\_w(r)(0 ≤ r ≤ R\_w) 위에 n\_c 영역(0–5 cm, 파랑)과 n\_edge 영역(12–14.5 cm, 주황). "계산 후 얻을 결과의 형태 · 값은 아직 미산출".
- 오른쪽 상자 셋: ① 최종 정상상태 2D 해, ② 웨이퍼 관측면 단면, ③ 성능 지표.
- 가운데 요약식과 "새 물리 방정식 없음: 수렴한 2D 밀도 지도의 단면을 잘라 면적 가중 평균으로 지표 계산".
- 결론 줄: 주어진 운전 조건에서 n\_e\*, T\_e\*를 산출하는 계산 과정이 완성된다.
- 각주: 계산 과정의 완성이며, 독립 제어 가능성의 입증 단계는 아님 · 지표는 면적 가중 평균(dA = 2πr dr, 부록).

**식. 상자 ①②③과 요약식**

$$
T_e^*(r,z),\; n_e^*(r,z) \;\longrightarrow\; n_w(r) = n_e^*(r, z_w) \;\longrightarrow\; \bar{n}_w,\;\; \rho = \frac{n_c}{n_{\mathrm{edge}}}
$$

$$
(P_{\mathrm{tot}}, k, \phi) \to \text{2D \, self-consistent} \to \left(T_e^*(r,z),\, n_e^*(r,z)\right) \to (\bar{n}_w, \rho)
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| T\_e\*(r, z), n\_e\*(r, z) | 수렴한 2D 온도·밀도 지도 | V, m⁻³ |
| z = z\_w | 관측면(웨이퍼 바로 위 높이) | m |
| n\_w(r) | 관측면 위의 반경 방향 밀도 곡선. 윗줄이 없으면 r의 함수, 있으면(n̄\_w) 숫자 하나 | m⁻³ |
| R\_w | 관측면 평가 반경(r\_2 이상) | m |
| 0–5 cm | 중앙 영역 예시. r\_c = 5 cm |  |
| 12–14.5 cm | 가장자리 고리 예시. r\_1 = 12 cm, r\_2 = 14.5 cm |  |
| dA = 2πr dr | 반지름 r, 폭 dr인 얇은 고리의 넓이 | m² |
| 그림의 r, z 축 | 지도의 가로(반경)·세로(높이) 축 |  |
| n\_c, n\_edge, n̄\_w, ρ, P\_tot, k, φ | 앞 장과 같다 |  |

요약식의 가운데 "2D 자기일관 계산"은 7–11장 전체를 상자 하나로 접어 둔 것이다.

**해설**

- 계산이 끝나면 무엇이 나오는지 보여 주는 "결과의 틀"이다. 그림이 비어 있는 것은 아직 계산을 돌리지 않았기 때문이고, 각주가 이를 밝힌다.
- 지표는 밀도 지도에서만 뽑는다. T\_e의 영향은 이미 밀도 분포에 반영돼 있기 때문이다.
- 2장의 지표로 돌아오는 장이다. z\_w 높이의 단면 n\_w(r)에 2장의 면적 평균을 적용해 n\_c, n\_edge, n̄\_w를 구한다. 바깥 고리가 넓으므로 r로 가중해야 한다.
- 요약식은 2D 모델 전체를 "입력 3개 → 출력 2개"인 상자 하나로 접어 놓은 것이다. 이 접은 형태가 13장의 출발점이다.
- 결론 줄은 "계산 과정이 완성된다"이지 "독립 제어가 된다"가 아니다. 한 운전점의 답을 얻는 도구가 갖춰졌다는 뜻이다.

**다음 장으로**: 이 도구를 여러 운전점에 돌려 제어 가능성을 판정한다.

## 슬라이드 13 · 제어 가능성 판단

여러 운전점의 수렴해를 비교해 2×3 감도 행렬 J\_ctrl을 만들고, 평균 밀도를 맞춘 뒤에도 전류비가 밀도비를 바꾸면 형상 제어 자유도가 있다고 판정한다.

**화면 구성**

- 부제: 판정 방법 · 여러 운전점의 수렴해 비교 → 입력 변화에 대한 평균 밀도와 밀도비.
- 입출력 관계 식과 주석 "압력 p 고정 · 계산 1회 = 입력 1조합 → 출력 1조합".
- 국소 민감도 식과 주석 "1행: 평균 밀도 감도, 2행: 밀도비 감도, 운전점별 수렴해의 수치 미분".
- 왼쪽 아래 "의미: 제어 가능성 판단": 세 입력이 평균 밀도와 밀도비를 서로 다른 방향으로 움직일 수 있는지 확인. 1행만 0으로 묶고(평균 유지) 2행이 0이 아니면 형상만 바꾸는 입력 조합이 존재. 2D 풀이용 Newton 행렬과는 다른 행렬.
- 오른쪽 아래 "예시 — 평균 밀도 유지 + 전류비만 변경": 번호 붙은 4단계.
- 결론 줄: 평균 밀도를 맞춘 뒤에도 전류비가 밀도비를 바꾸면, 형상 제어 자유도가 있다.
- 각주: 정적 국소 감도(시간 전달함수 아님) · 구동 범위·전류/전압 제한·수치 오차 검토 전에는 독립 제어 입증 아님.

**식 1. 입출력 관계와 국소 민감도**

$$
\mathbf{u} = (P_{\mathrm{tot}}, k, \phi) \;\longrightarrow\; \mathbf{y} = (\bar{n}_w, \rho)
$$

$$
\begin{bmatrix} \Delta \bar{n}_w \\ \Delta \rho \end{bmatrix} \simeq \underbrace{\begin{bmatrix} \partial_P \bar{n}_w & \partial_k \bar{n}_w & \partial_\phi \bar{n}_w \\ \partial_P \rho & \partial_k \rho & \partial_\phi \rho \end{bmatrix}}_{\mathbf{J}_{\mathrm{ctrl}} \in \mathbb{R}^{2\times 3}} \begin{bmatrix} \Delta P \\ \Delta k \\ \Delta \phi \end{bmatrix}
$$

| 기호 | 의미 | 단위 |
| --- | --- | --- |
| u | 입력 벡터 (P\_tot, k, φ) |  |
| y | 출력 벡터 (n̄\_w, ρ) |  |
| p | 기체 압력. 이 판정에서는 고정 | mTorr |
| Δ | 기준 운전점에서의 작은 변화 |  |
| ΔP | 총 전력의 변화량. 13장의 P는 P\_tot | W |
| Δk, Δφ | 전류비·위상차의 작은 변화 | –, rad |
| ∂\_P n̄\_w | 전력만 조금 올렸을 때 평균 밀도가 변하는 비율 | m⁻³/W |
| ∂\_k n̄\_w | 전류비만 바꿨을 때 평균 밀도 변화율 | m⁻³ |
| ∂\_φ n̄\_w | 위상차만 바꿨을 때 평균 밀도 변화율. 주로 간섭항을 통해 흡수 전력이 바뀌는 효과 | m⁻³/rad |
| ∂\_P ρ | 전력만 바꿨을 때 밀도비 변화율. 단일 코일에도 있는 형상 변화 | 1/W |
| ∂\_k ρ (= ∂ρ/∂k) | 전류비가 밀도비를 직접 바꾸는 정도 | 무차원 |
| ∂\_φ ρ | 위상차가 밀도비를 직접 바꾸는 정도 | 1/rad |
| J\_ctrl | 제어 야코비안. 위 여섯 편미분을 모은 행렬 |  |
| ∈ ℝ^(2×3) | 실수 성분의 2행 3열 행렬이라는 뜻 |  |
| ≃ | 1차(선형) 근사. 변화가 작을 때만 성립 |  |
| Newton 행렬 | 11장에서 격자 위 미지수를 풀 때 쓰는 내부 행렬. J\_ctrl과는 다른 것 |  |

J\_ctrl을 구하는 방법은 이렇다. 기준점에서 입력을 하나씩 조금 바꿔 다시 수렴해를 구하고, 출력 변화를 입력 변화로 나눈다(유한 차분). 이런 편미분 여섯 개를 모은 것이 J\_ctrl이다.

**식 2. 예시 4단계: 평균 밀도 유지 + 전류비만 변경**

1. 평균 밀도 유지(1행 = 0): ∂\_P n̄\_w ΔP + ∂\_k n̄\_w Δk + ∂\_φ n̄\_w Δφ = 0.
2. Δφ = 0으로 두면 평균을 지키는 전력 보정량은 ΔP = −(∂\_k n̄\_w / ∂\_P n̄\_w)Δk다. 전력이 평균을 움직일 수 있어야 하므로 ∂\_P n̄\_w ≠ 0이 필요하다. 0D만 봐도 사실상 성립한다(n\_0 ∝ P\_abs).
3. 밀도비 변화(2행에 ΔP 대입): Δρ = ∂\_Pρ ΔP + ∂\_kρ Δk.
4. 정리하면 아래 식이 된다.

$$
\Delta \rho = \left[ \frac{\partial \rho}{\partial k} - \frac{\partial \rho}{\partial P}\, \frac{\partial_k \bar{n}_w}{\partial_P \bar{n}_w} \right] \Delta k
$$

괄호 안은 평균 밀도를 고정한 채로 본 k의 순수한 형상 감도다. 앞 항은 k가 ρ를 직접 바꾸는 몸이고, 뒷 항은 평균을 맞추려고 전력을 보정할 때 ρ가 덩달아 바뀌는 몸이다. 이 차이가 0이 아니면 형상 제어 자유도가 있다.

**해설**

- 행렬로 보는 이유: 출력 두 개를 마음대로 움직이려면 두 행이 서로 다른 방향을 가리켜야 한다. 행렬의 계수(rank)가 2여야 한다는 뜻이다. 두 행이 평행하면 어떤 입력을 써도 n̄\_w와 ρ가 함께만 움직인다.
- 이 틀로 보면 단일 코일은 2×1 행렬이라 계수가 2일 수 없다. 3장의 결론이 그대로 다시 나온다. 0D에는 두 번째 행 자체가 없다(5장 문제 1).
- 계수가 2이면 입력 3개에서 남는 자유도 1개를 전력 최소화나 전류 한계 회피에 쓸 수 있다.
- Newton 행렬과의 구분: Newton 행렬은 11장에서 격자 위 수천 개 미지수를 푸는 내부 도구다. J\_ctrl은 그 계산을 여러 번 돌려 얻는 2×3 감도표로, 역할이 다르다.
- 각주 ① 정적 감도: 정상상태끼리 비교한 것이라 입력을 바꾼 뒤 얼마나 빨리 반응하는지는 담지 않는다.
- 각주 ② 국소 감도: 기준점 근처의 작은 변화에만 유효하다. 필요한 만큼의 ρ 변화를 구동 범위와 전류·전압 한계 안에서 낼 수 있는지는 따로 확인해야 한다.
- 각주 ③ 수치 오차: 입력 변화 폭이 수렴 허용 오차보다 충분히 커야 한다. 그렇지 않으면 "감도"가 계산 잡음일 수 있다.
- 결론 줄은 2장의 목표(Δn̄\_w = 0, Δρ ≠ 0)를 수학적 판정 기준으로 바꾼 것이다. 발표가 2장으로 돌아오며 닫힌다.
