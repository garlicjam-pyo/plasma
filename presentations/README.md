# presentations

발표 자료. 이 프로젝트의 PPT는 모두 `template/발표양식_4x3.pptx`(수업 양식, 4:3)로 만든다.

| 파일 | 내용 |
| --- | --- |
| `1차발표_최종.pptx` | 설계 포함판 (11-06, 본편 28장 + 백업 13장, 발표자 노트 포함). 11-09부터 1차 발표는 위 이론 배경판으로 진행하고, 이 판은 2차 준비 자료로 둔다. 수업 가이드라인에 맞춘 **2차 주제를 위한 이론 학습** 흐름: 주제와 학습 범위 → ICP 밀도 분포의 원리(유도 결합 기초, 식 1–7, [Pa17]) → 조절 수단의 원리(LC 공진, KC20, 위상·진폭, 자기장·페라이트) → 밀도비 측정 이론(진단 비교, FHP) → 주제와의 연결(단순 제어의 한계, 운전 압력, 2차 설계 방향·계획). 설계 초안(구성도, 운용, 조정 절차, 가설)은 백업 |
| `1차발표_이론배경판.pptx` | **1차 발표 진행본 (11-09, 교수 피드백 반영).** 팀 이론판(같은 양식)을 직접 고친 것. 본편 15장 + 참고문헌 + 숨긴 부록 2장(모델 교차 영향 예시, 결합 회로식), 발표 16분을 네 구간으로 나눔(노트에 [발표 n]과 쪽별 발표 시간): 주제와 ICP 전자 가열(1–5) → 코일 결합과 수송(6–9) → 밀도 형성과 독립 제어(10–12) → 밀도 진단과 2차 연결(13–15). 이 파일은 `src/build.py`로 만들지 않는다 |
| `template/발표양식_4x3.pptx` | 수업 발표 양식 (제목·제목만 레이아웃, 바닥글 로고) |
| `src/build.py`, `src/lib.py` | 양식 위에 슬라이드를 만드는 스크립트 (python-pptx) |
| `src/eq/` | 수식 이미지와 원본 LaTeX (`eqs.json`, KaTeX로 렌더링하는 `render.js`) |

## 다시 만들기

```bash
python -m pip install python-pptx
python presentations/src/build.py presentations/template/발표양식_4x3.pptx presentations/1차발표_최종.pptx
```

수식을 고치면 `src/eq/eqs.json`을 바꾸고 `node render.js`로 PNG와 `sizes.json`을 다시 만든다 (katex, playwright 필요).

## 양식 사용 규칙 (1차 발표에서 정한 것)

- 레이아웃: 표지는 `제목 슬라이드`, 본문은 `제목만`. 제목은 한 줄(28 pt), 제목 아래 파란 선 밑에 구분 줄(12 pt)을 둔다.
- 본문 글자는 12 pt 이상, 각주만 10 pt. 쪽 번호는 바닥글 오른쪽.
- 본편 슬라이드 형식: 구분 줄은 `장 · 이 쪽의 역할 · (제출물/검토 사항)`, 본문은 제목 아래 1.42–5.75 in 안, 그 아래 핵심 메시지 한 줄(→, 5.88 in)과 출처·계산 조건만 담은 각주 한 줄(6.47 in). 표지·목차·참고문헌은 핵심 메시지 없음.
- 팀 질문 번호(질문 x-x)는 백업 B7 대응표와 백업 슬라이드에만 쓴다.
- 색의 뜻: 파랑 = 중앙·안쪽 코일, 주황 = 가장자리·바깥 코일, 남색·양식 제목색 = 구조·결론, 호박색 = 한계·누설·주의. 바탕은 흰색·옅은 회색만 쓴다.
- 학회 발표 스타일(11-06): 모서리는 각지게, 내용 블록은 흰 바탕 + 얇은 테두리 + 위쪽 색 선, 표는 booktabs식(머리 채움 없음, 위·아래 굵은 선), 번호는 원 대신 굵은 숫자, 식 번호는 (1a) 꼴, 결론 한 줄은 채운 상자·화살표 없이 위쪽 선 + 굵은 글씨, 구분 줄은 회색. 큰 숫자 카드 대신 표로 값을 보인다.
- 차트는 PowerPoint 기본 차트로 넣어 편집할 수 있게 한다. 목표 범위(R 0.8–1.2)는 옅은 회청색 띠로 통일.
- 수치 옆 표시: (계산) / (추정) / (가정).
- 교재 장·식 번호는 슬라이드에 쓰지 않고, 공식을 슬라이드 안에서 직접 보여 주며 덱 안의 번호(식 1–7)로 앞뒤를 잇는다.
