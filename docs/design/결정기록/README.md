# 결정 기록 (ADR)

결정 하나에 파일 하나. 뒤집을 때는 새 ADR을 쓰고 이전 ADR의 상태를 "대체됨 (→ ADR-NNN)"으로 바꾼다.
상세 근거는 [`../../06_상세설계보고서.md`](../../06_상세설계보고서.md)(유도·수치)와 [`../../05_1차_결정보고서.md`](../../05_1차_결정보고서.md)(요약),
2026-11-05 검토에서 고친 내용은 [`../../07_검토결과_2026-11-05.md`](../../07_검토결과_2026-11-05.md)에 있다. 아래 ADR은 검토 결과를 반영한 판이다.
